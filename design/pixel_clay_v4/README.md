## 0. 이 프로젝트가 무엇인가

**2ndB** — "AI 시대에 가장 가치 있는 자산은 나 자신"이라는 전제에서 출발한 개인 데이터 앱입니다.
흩어진 일상을 담아 **나를 아는 AI(세컨비)** 를 기르고, 그 AI가 나를 대신해 판단을 돕습니다.

디자인은 **픽셀아트(PIXEL-CLAY v4)** 로 만들었습니다. 390×820 폰 프레임, 92개 라우트, 8종 오버레이.

## 4. 코드를 만질 때 반드시 알아야 할 것

### 4-1. 절대 규칙 (어기면 디자인이 깨집니다)
| 항목 | 규칙 |
|---|---|
| 도형 | 정수좌표 `<rect>` 만. `<path>`/`<circle>`/`<polyline>` 금지 |
| 라운드 | `border-radius: 0` — 프레임 전체 강제 |
| 블러 | `blur()`·`backdrop-filter` 금지 → **디더 스크림**(`.ds-scrim`) |
| 불투명도 | 정적 opacity 금지 → **색 밴딩** 또는 **50% 디더** |
| 모션 | `steps()` 이징만 |
| 입체 | 4방향 베벨. 2변 'ㄱ'자 금지 |
| 색 | 하드코딩 hex 0건 — 토큰 또는 `pixel-deepspace.css` 액센트 변수 |

### 4-2. 자주 밟은 함정
| 함정 | 결과 | 올바른 방법 |
|---|---|---|
| `C('outline')` 을 본문 텍스트에 | 배경과 구분 안 됨 (같은 값) | `C('on-surface-variant')` |
| `getBoundingClientRect` 로 좌표 계산 | 폰 프레임 스케일(0.629)이 곱해져 어긋남 | `offsetWidth`/`offsetHeight` |
| 인라인 `background` 로 창 스타일 덮기 | CSS 규칙이 져서 창이 사라짐 | `.ds-window` 에 맡기기 |
| 화살표 상수를 `return` 아래에 선언 | 호이스팅 안 돼 앱 크래시 | `function` 선언 |
| 팬 중 매 프레임 `setState` | 그래프 전체 재렌더로 끊김 | transform 직접 쓰고 놓을 때 1회 커밋 |
| JSX 자식 위치에 `/* 주석 */` | 화면에 글자로 새어나옴 | `{/* 주석 */}` |
| `overflow: hidden` 을 스크롤 컨테이너 자식에 | 높이가 스크롤에 반영 안 돼 잘림 | 자식에서 제거 |

### 4-3. 파일 구조
```
app/
  2nd-Brain.html        진입점 · 스크립트 로드 순서
  px-bridge.css         M3 어휘 → PIXEL-CLAY 토큰 브리지
  pixel-deepspace.css   딥스페이스 브랜드 레이어 (유일한 hex 허용 구역)
  px-primitives.jsx     Md* 프리미티브 · Icon 매핑 · SbHead · DialogBox
  px-avatar64.js        64×64 아바타 생성기 (138종)
  sb-app.jsx            셸 · 라우터 · 탭바 · 오버레이  ← 마지막에 로드
  sb-data.jsx           공유 데이터 · 대화 피드 · 리즈닝·공지 상태
  sb-wikigraph.jsx      위키 그래프 (물리 · 카메라 · 라벨 충돌 회피)
  sb-persona.jsx        페르소나 덱 · Big Five 레이더 · 적합성 이론
  ...                   그 외 20여 파일 (화면별)
```

**로드 순서** — React → Babel → PIXEL-CLAY 번들 → 확장팩 → `px-avatar64` → `px-primitives` → `sb-data` → 화면들 → `sb-app`

**중요** — 각 `<script type="text/babel">` 은 독립 스코프입니다. 공유 컴포넌트는 파일 끝에서 `window` 에 내보내야 합니다.

## 5. 아직 열려 있는 것

| 항목 | 상태 |
|---|---|
| 법률 문서 본문 | 절 구조만. 법무 원문 대기 |
| 사업자 정보 | 자리표시자 값 |
| `digest` 이름 혼동 | 주간 다이제스트 vs 오늘의 정리 — 하나 은퇴 또는 개명 필요 |
| 밝기 L1~L5 계산 | '분류됨' 기준, 검증도구 1개=L4 여부 미확정 |
| 알림 정책 | `digest` 로컬 9시만 정의 |
| EN 카피 | KO만 진행 (KO/EN 패리티가 불변식인데 EN 원문 없음) |
| 인트로 화면 | 별도 제작 예정 (자리만 확보) |
| 시각 방향 | PIXEL-CLAY vs Material 3 — 비준 대기 |
