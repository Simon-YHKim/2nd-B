# 결정 기록 — 왜 이렇게 생겼는가

> 이 세션에서 사용자와 주고받으며 내린 판단들. PRD는 "무엇을"이고, 이 문서는 "왜"입니다.
> Claude Code가 같은 결정을 되풀이하거나 되돌리지 않도록 근거를 남깁니다.

---

## 1. 시각 방향 — Material 3 → PIXEL-CLAY

**배경** — 처음엔 수제 M3 프로토타입(`reference-app/`)을 공식 Material 3 번들로 마이그레이션했습니다(`migrated-app/`, 56개 상태 완료). 그 뒤 사용자가 **픽셀아트로 전환**을 요청했습니다.

**판단** — 레이아웃·한국어 카피·딥스페이스 아이덴티티는 유지하고 시각 기반만 PIXEL-CLAY로 교체. 별하늘은 도트로, 프레임은 사각으로, 스크림은 디더로 "번역"했습니다. 원형 유지가 불가능한 규칙(라운드·블러·그라데이션 금지)이라 재해석이 필요했습니다.

**보존** — `migrated-app/`은 지우지 않았습니다. 시각 방향은 아직 비준 대기입니다.

## 2. 별자리 구조

### 2-1. 7번째 별을 커뮤니티로
뮤지엄이 차지하던 7번째 슬롯을 커뮤니티로 교체했습니다. 커뮤니티는 **도메인이 아니라 포탈**이므로 밝기 L1~L5가 없고 북극성 평균에서 제외됩니다. 시각적으로도 속이 빈 보라 윤곽 별로 구분합니다. 뮤지엄은 홈 좌측 코너 버튼으로 이동.

### 2-2. 7별 정렬 통일
`/growth`의 북두칠성이 Layer B 심리 구인 7개(지금의 나·회상·보여지는 나…)를 쓰고 홈은 생활 도메인 7개를 써서, "이번 주 가장 밝아진 별"이 어느 축인지 모호했습니다. **홈 기준 생활 도메인으로 통일**했습니다.

### 2-3. 위키 그래프 3티어
```
티어1 북극성(중심) → 티어2 도메인 6개(정육각형) → 티어3+ 별가루(부채꼴)
```
처음엔 별가루 좌표를 도메인 기준으로 잡았더니 옆 구획을 침범했습니다. **북극성 중심 극좌표**로 바꿔 침범이 구조적으로 불가능하게 만들었습니다. 도메인 별은 꼭짓점 영구 고정(드래그해도 안 움직임), 별가루는 제 구획 안에서만 끌립니다.

**담아내기 별 제거** — 미분류 보관함이라 6각형 구조를 흐렸습니다.

## 3. 진입 흐름을 짧게

**처음** — 4슬라이드 온보딩 + 로그인 슬라이드
**최종** — 인트로(환영 1장) → 로그인/회원가입 → 프로필 설정 → 별자리

사용자 요청: "환영하는 화면 정도만 보여주고 바로 프로필 설정으로". 슬라이드 4장은 제품 설명이었는데, 쓰기 전에 읽히지 않는다는 판단입니다.

**프로필 설정으로 동의를 옮김** — 회원가입 화면과 프로필 설정에 생년월일이 중복돼 있었습니다. PIPA 동의 5항목을 프로필 설정의 '시작하기' 위로 옮겨 한 곳에서 끝나게 했습니다.

## 4. 세컨비(AI 캐릭터) 표현

### 4-1. 말풍선 → 2D 픽셀 대화창
말풍선 + 머리 조합을 게임 대화창 형식으로 바꿨습니다. 초상은 **대화창 내부 좌상단**(48px), 이름판은 초상 위. 홈·담기·위키·매뉴얼 등 이 조합이 나오는 모든 화면에 공용 컴포넌트(`DialogBox`)로 적용.

### 4-2. 담기 화면에서 제거
집중이 필요한 화면이라 대화창을 없앴습니다.

### 4-3. 위키에서는 하단으로 + 튜토리얼 역할
그래프가 화면을 넓게 쓰도록 대화창을 하단(탭바 위)으로 내렸고, 역할을 **첫 진입 3장 안내**로 바꿨습니다. 안내가 끝나면 접혀서 작은 세컨비 단추만 남습니다.

### 4-4. 피드 구성
방금 담긴 자료 → 분석 결과 → 혼잣말(3개마다) → **AI 뮤지엄 이야기(2개마다)**. 뮤지엄 장에는 `보러가기`, 기록 장에는 `이 글 보기` 버튼이 붙습니다.

## 5. 아바타 — 16×16 → 64×64

**문제** — 16칸 스프라이트를 48px로 띄우면 한 칸이 3px로 뭉갰습니다.

**전량 이전** — 헤어 24 · 액세서리 20 · 얼굴 14 · 표정 10 · 동물 26 · 직업 44 = **138종**. 64칸이라 명암(좌상단 광원), 흰자·눈동자·반사광 분리, 눈썹·코·입술 음영, 볼 홍조, 옷 소매·칼라가 들어갑니다.

**규칙**
- 동물은 종별 허용 털색만 (개구리 초록, 판다 흰색) — 무작위 검은 토끼가 나오지 않게
- 밝은 머리·털색이면 눈썹 최소 대비 보장
- 작은 칩(40px 이하)은 머리 영역만 crop해 한 칸 = 1px 유지
- 16 그리드 저장본은 인덱스 형식을 흡수해 보존 (시드 재생성 안 함 — 여우로 저장했으면 여우로)

**페르소나별 아바타** — 얼굴은 프로필 그대로, 직업만 갈아끼웁니다. 같은 사람이 1인 개발자·가장·학습자로 달리 보입니다. 동물 아바타는 직업 옷을 입힐 수 없어 원래 모습 유지.

## 6. 페르소나 카드

**구성** — 아바타(세로 중앙) → 영역 배지 → 역할 이름 → **내 브랜드**(퍼스널 브랜딩 한 줄) → 서브텍스트 → 강점 칩

**커리어 카드만** Big Five + 적합성 이론:
- 레이더는 번들 차트(44칸)로는 오각형이 뭉개져서 **88칸에 직접 래스터화**. 데이터 면은 50% 디더(불투명도 금지 대응)
- **적합성 이론** — 처음 단일 P-E Fit 점수로 만들었다가, 사용자 지적으로 Holland RIASEC 코드 + 하위 적합도 3종(P-J 직무 · P-O 조직 · P-V 진로)으로 확장
- 3줄 요약에 **조사 자동 판정** (숫자는 읽는 소리, 한글은 종성)

**CTA는 덱 고정 푸터로** — 카드 안에 두면 스크롤 밖으로 밀려 닿지 않았습니다.

## 7. 카피

### 7-1. 어려운 말을 쉬운 말로 (47곳)
"비준 했어요" 같은 표현이 어렵다는 지적. 비준→확인, 승인/보류/거절→맞아요/나중에/아니에요, 검증틀→검사, 파생 신호→분석 결과, 열람→보기, 근거→이유.

**주의** — `/ratifications`의 4열 요약 스트립 열 이름이 바뀌면서 "보류/거절은 항상 0"이라는 정직성 표기의 의미가 달라질 수 있습니다. PRD 판정 대기 항목입니다.

### 7-2. 당연한 것은 쓰지 않는다
"생년월일은 공유하지 않아요", "연락처는 저장하지 않아요", "이미지를 보관하지 않고 학습에 쓰지 않아요" — 약관에 있을 내용이라 화면에서 제거. 단 약관·처리방침·동의 항목 안내는 법적 명시가 필요해 유지.

### 7-3. 브리프 카피와의 충돌
브리프는 "카피 원문 고정"이지만 사용자 지시로 7곳을 바꿨습니다(로그인 히어로 정리, 추천 답변 칩 제거 등). `COPY_CONFLICTS.md`에 정리해 판정 대기 중입니다.

## 8. 성능 — 왜 끊겼는가

세 가지가 겹쳐 있었습니다.

1. **팬할 때마다 React 상태 갱신** — 마우스 이동 한 번에 그래프 전체(노드 25 + 연결선 26 + SVG 29)가 재렌더. 드래그 중엔 transform만 직접 쓰고 놓을 때 1회 커밋으로 바꿨습니다.
2. **상시 드리프트** — 물리가 멎은 뒤에도 매 프레임 전 노드·엣지를 다시 썼습니다(유휴 800ms에 6만 5천 번). 얻는 건 0.3px 흔들림. 제거하고 정수 좌표로 스냅했습니다.
3. **자동 재적합** — 물리 정착 시 배율을 다시 맞추면서 사용자가 팬 중이던 화면을 중앙으로 되돌렸습니다. 한 번이라도 조작하면 재적합하지 않게 했습니다.

정착 후에는 rAF 루프 자체가 멈추고, 상호작용이 있을 때만 깨어납니다.

## 9. 위기 라우팅 (CrisisRouter)

**톤 규칙** — 위험색·경고 아이콘·애니메이션 **금지**. 중립 무드 세컨비 소형 1개만.

**셸 최상위 오버레이** — 상태바·탭바까지 완전히 덮어 이탈 불가. 화면 안 오버레이로 두면 탭으로 빠져나갈 수 있었습니다.

**핫라인 3변형** — KO 성인 109 / KO 미성년 1388+109 / EN 988. `tel:` 로 OS 다이얼러 위임.

**고지 상시** — "입력한 내용은 저장되지 않아요 · 횟수가 차감되지 않아요"

트리거 6지점(대화·담기·음성 전사·통화 녹음·북극성 문장·리즈닝 배치)은 시연 화면에 목록으로 있고, `env.openCrisis({locale, minor})` 로 어디서든 부를 수 있습니다.

## 10. 감사 사이클

PRD를 보유한 다른 세션에 두 차례 감사를 받았습니다.

**1차** — 브리프 62개 대비 22개 누락 발견 → 전부 구현 (A 인증·법률 6 / B 검증 2 / C 세컨비 3 / D 담기 3 / E 위키 4 / F 커리어·재정 4 / G 생활 4)

**2차** — 누락 9건 지적 → 8건 구현(`/persona`는 승인된 생략), 고아 화면 1곳 진입 신설, CrisisRouter 신규, 티어 명칭 확정(별바라기·항해자·북극성)

**대조 화면** — 브리프와 기존 구현의 성격이 다른 3쌍(`digest`·`people`·`rest`)은 지우지 않고 병치해 비교할 수 있게 했습니다.
