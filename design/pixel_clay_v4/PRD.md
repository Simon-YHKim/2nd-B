> 이 문서는 **구현된 코드에서 역으로 추출한 정본**이다. 화면 목적 · 구성 · 버튼 · 상태 · 데이터를 모두 기술한다.

## 1. 제품 정의

### 1-1. 한 줄
AI 시대에 가장 가치 있는 자산은 나 자신이다. 흩어진 일상을 담아 **나를 아는 AI(세컨비)** 를 기르고, 그 AI가 나를 대신해 판단을 돕는다.

### 1-2. 두 축
| 축 | 내용 | 대표 화면 |
|---|---|---|
| **알아가기** | 기록을 담아 7개 생활 도메인의 별을 밝힌다 | 담기 · 위키 · 북극성 |
| **곁에서 돕기** | 알게 된 만큼 비서가 된다 | 세컨비 대화 · 오늘의 비서 · 리즈닝 |

### 1-3. 불변 원칙
1. **propose → ratify** — 세컨비는 제안만 한다. 승인 없이 어떤 분석도 별에 반영되지 않는다.
2. **비차단 분석** — 분석은 진행바 모달로 사용자를 막지 않는다. 하단 독에서 돌고, 끝나면 토스트로 알린다.
3. **근거 제시** — 모든 판단에 원본 기록으로 가는 경로를 남긴다.
4. **한 화면 한 메시지** — 화면마다 사용자가 할 일 하나.
5. **위기 우선** — red-zone 입력은 LLM 호출 없이 도움 연결로 단락. 쿼터 미차감, 원문 미저장.
6. **터치 타깃 44px 이상** · **reduced-motion 존중**

## 2. 디자인 시스템 계약 (PIXEL-CLAY v4)

### 2-1. 절대 규칙
| 항목 | 규칙 |
|---|---|
| 도형 | 정수좌표 `<rect>`만. `<path>`/`<circle>`/`<polyline>` 금지 |
| 라운드 | `border-radius: 0` — 전 화면 강제 |
| 블러 | `blur()` · `backdrop-filter` 금지 → **디더 스크림**으로 대체 |
| 불투명도 | 정적 opacity 금지 → **색 밴딩** 또는 **50% 디더** |
| 모션 | `steps()` 이징만. 곡선 이징 금지 |
| 입체 | 4방향 베벨 (2변 'ㄱ'자 금지) |
| 색 | 하드코딩 hex 0건 — 토큰 또는 `deepspace.css` 액센트 변수 |

### 2-2. 토큰 브리지
`px-bridge.css`가 M3 어휘(`--md-sys-color-*`, `.md-*` 타입, `.md-interactive`)를 PIXEL-CLAY 토큰으로 해석한다. 화면 코드는 M3 어휘를 쓰고 시각은 번들 토큰을 따른다.

| M3 역할 | PIXEL-CLAY |
|---|---|
| surface / on-surface | `--bg` / `--fg` |
| on-surface-variant | `--fg-muted` |
| surface-container(-high/-highest) | `--panel` / `--panel-2` |
| primary / on-primary | `--accent` / `--accent-fg` |
| tertiary | `--ds-nebula` (딥스페이스) |
| error | `--danger` |
| outline(-variant) | `--edge-soft` |

**금지**: `C('outline')`을 본문 텍스트에 쓰는 것 — 보더 전용 토큰이라 배경과 구분되지 않는다. 본문 보조는 `C('on-surface-variant')`.

### 2-3. 딥스페이스 브랜드 레이어 (`pixel-deepspace.css`)
번들에 없는 커스텀. 유일한 리터럴 hex 허용 구역.

- **별빛**: `--ds-star #CCFAFF` · `--ds-core #46B6FF` · `--ds-polaris #C8B6FF`
- **성운**: `--ds-nebula #A78BFA` / `-deep` / `-soft`
- **무드**: positive `#5FF0C0` · neutral `#A78BFA` · negative `#FF7A90`
- **`--ds-edge`**: 4방향 1px 테두리 (창·카드·버튼 공통)
- **`.ds-scrim`**: 8px 격자 디더 오버레이 (블러 대체)
- **`.ds-window`**: 창 표면. 다크에서 `color-mix(--panel 86%)` — 별하늘이 은은히 비친다
- **`ds-tw`**: fill 스왑 트윙클 (opacity 애니 금지 준수)
- **`sb-bob`**: 1유닛 홉

### 2-4. 타이포
Galmuri 픽셀 폰트. 크기는 10/12/15/24/30/45px만. `--font-micro`(10px 전용) · `--font-ui` · `--font-display` · `GalmuriMono11`(숫자·라벨).

## 4. 진입 흐름 (gate)

### 4-1. 흐름
```
인트로(환영) → 로그인/회원가입 → 프로필 설정 → 별자리(홈)
```
프로필을 마쳐야 홈에 도달한다. 프로필 입력 중에는 TTFV 오버레이가 뜨지 않는다.

### 4-2. `/auth` 로그인
**목적** — 계정 확인. 프로필 설정으로 보낸다.

**구성** (창·앱바 없음, 별하늘 전면)
1. 세컨비 머리 80px + **2ndB** (30px, 앱 이름만 — 부제·암호화 문구 없음)
2. 이메일 · 비밀번호 필드. 비밀번호에 **눈 아이콘** 토글(표시 중엔 사선)
3. `로그인` / `회원가입` 버튼 — 둘 다 프로필 설정으로
4. 소셜 5종 — 카카오 · 네이버 · 구글 · 애플 · GitHub. **전부 16×16 픽셀 그리드 재작화**(곡선·AA 0). 구글만 4색 유지(브랜드 규정)
5. `비밀번호를 잊으셨나요?` → 계정 찾기
6. **사업자 정보 푸터** — 상호 · 대표 · 주소 · 사업자등록번호 · 통신판매업 신고번호 · 개인정보담당 · 대표번호를 `항목 : 값` 형식으로. 면책 문장 + 약관·처리방침·환불정책 링크 + "계속하면 위 약관과 처리방침에 동의하게 돼요."

### 4-3. `/signup` 회원가입
**구성**: 세컨비 56px + `회원가입` → 이메일 · 비밀번호(8자 이상) · **비밀번호 확인** · 생년월일(**달력 시트**) → PIPA 동의 5항목 → `계정 만들기`

**유효성** — 버튼은 항상 누를 수 있고, 못 채운 항목이 있으면 **그 자리로 스크롤 + 붉은 테두리 + 사유 문구 + 토스트**. 검사 순서는 화면 순서와 같다.

| 검사 | 조건 | 문구 |
|---|---|---|
| 이메일 | `@` 포함 | 이메일 주소를 확인해 주세요. |
| 비밀번호 | 8자 이상 | 비밀번호를 8자 이상으로 정해 주세요. |
| 확인 | 일치 | 두 비밀번호가 서로 달라요. |
| 생년월일 | 형식 + **만 14세** | 만 14세 이상만 가입할 수 있어요. |
| 동의 | 필수 4 전부 | 필수 항목에 모두 동의해 주세요. |

**매직 입력값** (시안 검증용): `already@…` → 기존 계정 / 비밀번호 `password` → 유출 목록 / `@xprize.org` → 심사관 모드 / 그 외 → 6자리 코드 카드

### 4-4. `/pwreset` 계정 찾기
3모드 칩(비밀번호 찾기 · 아이디 찾기 · 비밀번호 재설정). **이메일 인증으로 통일** — 문자·휴대폰 없음.

- 입력부는 상단 고정. `인증코드 보내기`를 누르면 **화면이 바뀌지 않고** 안내 문구 아래에 코드 입력이 붙는다(키보드에 가리지 않도록 하단 고정이 아니라 본문 흐름)
- **5분 카운트다운** — 1분 미만이면 색 변화, 0이면 확인 잠금
- `코드 확인` + `코드 다시 보내기`
- 재설정 모드: 새 비밀번호 + **확인란**, 각각 눈 토글. 불일치 시 붉은 문구, 일치 시 초록
- 완료: `확인` 버튼 하나 → 로그인. 문구 "다른 기기는 모두 로그아웃됐어요. 새 비밀번호로 다시 로그인해 주세요."

### 4-5. `/profilesetup` 프로필 설정
**목적** — 시작 전 최소 인적사항 + 동의.

**구성**
1. 상단 **뒤로가기**(셸 `onBack` 우선, 게이트에서는 로그인)
2. `프로필을 마저 채워요`
3. **아바타** 96px + 모서리 사진 올리기 칩(44px 히트 영역 안에 30px 칩)
4. **아바타 프리셋 레일** — 가로 스크롤 + 사각 픽셀 스크롤바. `아바타 만들기` → 스튜디오
5. 이름 · 핸들 · 생년월일(달력) · 목표 — 각 항목에 **ⓘ 설명 버튼**(44×44, 세컨비 말풍선으로 용도·목적·팁)
6. **PIPA 동의 5항목** (회원가입 화면 정리 후 이리로 옮김)
7. `시작하기` — 미충족 시 `항목을 모두 채워주세요` / `필수 항목에 동의해 주세요`
8. 진행 표시(3/4)는 버튼 바로 위

### 4-6. `/peer-token` 지인 응답 랜딩 (무계정)
**목적** — 지인이 계정 없이 3문항에 답한다.

3특질 5점 척도 + 동의 체크(AI 처리 · 국외 이전 · 미성년 시 보호자 행). 4갈래: 폼 / 기응답(철회 가능) / 만료 / 무효. "세 명 이상 모였을 때 합산으로만 보이고 개별로는 절대 보이지 않아요."

## 5. 홈 · 별자리 (`/home`)

### 5-1. 목적
7개 생활 도메인을 별로 배치해 지금의 나를 한눈에. 세컨비와의 대화 진입점.

### 5-2. 별자리 구성
북극성(중앙, 12시 방향 큰 별) + 6개 도메인 별 + 커뮤니티 포탈.

| 별 | 성격 | 밝기 |
|---|---|---|
| 북극성 | 7별 종합 | — |
| 커리어 · 재정 · 성장 · 관계 · 건강 · 휴식 | 도메인 | L1~L5 |
| **커뮤니티** | **포탈** | **없음** — 속이 빈 보라 윤곽 별. 북극성 평균에서 제외 |

별은 **4꼭짓점 픽셀 별**. 등급별 밝기는 색 밴딩(L4+ star / L3 core / L1-2 c03). 선택 시 뒤에 큰 별이 겹쳐 후광.

### 5-3. 세컨비 대화창 (DialogBox)
2D 픽셀 대화창. **좌상단 초상 프레임(48px)** + 이름판(초상 위) + 대사 + `▼` 페이저.

**피드 순환**
1. 방금 담긴 자료 — `meta`(시각·형식)가 위, 제목이 아래. `이 글 보기` 버튼
2. 분석 결과 — `이 글 보기` 버튼
3. 세컨비 혼잣말 (3개마다)
4. **AI 뮤지엄 이야기** (2개마다) — 8편. `보러가기` → 해당 전시로 직행

초상을 탭하면 리즈닝 대화 4변형(idle / auto ON / 실행 중 / 한도 소진).

### 5-4. 페르소나 덱
북극성을 탭하면 카드 덱이 **스크림 없이** 뜬다(별하늘 그대로 보임).

**카드 구성**
1. 우상단 `n/total` 배지
2. **아바타 52px** — 그 역할의 직업 옷을 입는다(얼굴은 프로필 그대로, 직업만 교체)
3. 영역 배지 + 역할 이름(24px)
4. **내 브랜드** — 퍼스널 브랜딩 한 줄(15px, 굵게) + 서브텍스트
5. 강점 칩
6. **커리어 카드만**: Big Five 5각형 레이더 + 적합성 이론
   - **레이더** — 88칸 격자에 직접 래스터화. 동심 오각형 3겹(c03) + 바깥 링(c04) + 축. 데이터 면은 **50% 디더 채움**(불투명도 대신), 외곽선 core, 꼭짓점 star. 라벨은 이름+숫자 한 줄
   - **Holland 코드** — Big Five → RIASEC 6유형, 상위 3개(예: AIE) + 한글 이름
   - **하위 적합도 3종** — P-J(직무: 요구·능력) · P-O(조직: 가치 일치) · P-V(진로: 흥미 방향)
   - **3줄 요약** — Big Five 최고·최저 + 기복 / Holland 방향 / 적합도 강·약 축. **조사 자동 판정**(숫자는 읽는 소리, 한글은 종성)
7. 덱 **고정 푸터** — `문장 다듬기` / `내보내기` (스크롤 밖이라 항상 닿는다)

## 6. 담기 (`/capture`)

### 6-1. 목적
떠오른 순간을 편한 형식으로 담는다. 세컨비 대화창 없음(집중).

### 6-2. 형식 5종 (아이콘 위 · 라벨 아래, 한 줄 균등)
| 형식 | 입력 |
|---|---|
| 글 | 자유 텍스트 |
| 링크 | **처음 3칸 + `+` 아이콘**으로 늘림 (최대 5) |
| 사진 | 이미지 슬롯 + OCR |
| 음성 | 녹음 + 파일 업로드 |
| 할 일 | 체크 목록 |

### 6-3. 사진 · OCR
이미지 슬롯(글자·아이콘이 테마 색을 따름, "또는 파일 선택"). OCR 모드일 때 하단 버튼이 `담기` → **`글 추출하기`** 로 바뀐다.

`글 추출하기` → 팝업: 읽는 중 → 추출된 글(편집 가능) → 하단 `복사하기` · `담기` · `다시 추출`. 팝업을 닫아도 글은 남고 `크게 보기`로 재개.

### 6-4. 음성
1. 녹음 버튼(88px) — 누르면 파형 애니메이션
2. **실시간 받아적기** — 말하는 대로 어절이 붙고 커서 깜빡임. 멈추면 편집 가능한 텍스트로
3. `또는` 구분선
4. **녹음 파일 업로드** — m4a·mp3·wav. 이름·용량 표시 → `받아적기` → 진행바 → 편집 가능한 전사문 → `다시 받아적기`

담기 완료 시 음성·전사문도 함께 초기화된다.

### 6-5. `/capture-full` 전체 담기
8모드 풀 컴포저(일기 · 메모 · 링크 · 사진OCR · 문서 · 음성 · 할일 · 4W1H) + 트랙 토글(일상 Wiki / Pro Wiki) + OCR 승인 게이트 + 해시태그 + 최근 별가루.

## 7. 세컨비 대화 (`/chat`)

### 7-1. 목적
3렌즈(세컨비 · 메타비 · 트위비)로 나에 대해 묻고 답을 받는다. 상단 세컨비 머리·말풍선 없음(챗 자체 헤더가 붙는다).

### 7-2. 메시지 구성 (메신저 형식)
**말풍선 위에 보내는 이**
- 세컨비 쪽: 렌즈 액센트 색이 눈에 반영된 픽셀 머리(32px 글리프 / 40px 칩) + 이름 + **인용 칩(행 오른쪽 끝)**
- 내 쪽: 프로필 아바타(40px, 머리·어깨 crop) + 이름, 오른쪽 정렬

**5줄 클램프** — 넘치면 `더보기`(터치 44px, 말풍선 글자색) → 전문 팝업(스크롤)

**인용 칩** — 누르면 근거 목록 시트. 기록 8건이 제목·시각·형식·소속 별과 함께 나열.

### 7-3. 입력창
여러 줄로 자라는 textarea(최대 108px, 그 이상 스크롤). Enter 전송 / Shift+Enter 줄바꿈. 전송 후 한 줄로 복귀.

**대화 영역 연동** — 입력창이 자라면 대화가 그만큼 줄고 자동으로 바닥에 붙는다. 실기기 가상 키보드는 `visualViewport`로 감지해 입력 바를 키보드 위로 올린다.

### 7-4. 대화방 목록
행마다 **연필(이름 수정)** + 휴지통. Enter·체크로 저장, Esc 취소. 담기 버튼은 아이콘만(aria-label 유지).

## 8. 위키 (`/records`)

### 8-1. 목적
담은 별가루의 관계를 그래프로 본다. 그래프가 화면을 최대한 쓴다.

### 8-2. 그래프 배치 (3티어)
```
티어1 북극성(중심) → 티어2 도메인 6개(정육각형 꼭짓점) → 티어3+ 별가루(부채꼴 방사)
```
- **좌표는 북극성 중심 극좌표** — 도메인 기준이 아니라 중심 기준이라 옆 구획 침범이 구조적으로 불가능
- 각 도메인은 60° 구획 전부를 쓰되 경계에 최소 간격(WEDGE = 60°×0.96)
- 별가루는 한 줄 2개, 줄 간격 108px로 바깥 고리로 퍼진다
- **도메인 별은 꼭짓점 영구 고정** — 드래그해도 움직이지 않는다
- **별가루는 제 구획 안에서만** 끌린다(각도·반지름 클램프). 놓으면 물리가 제자리로

### 8-3. 별가루 노드
- **아이콘** — 테두리·글리프 색 = **소속 도메인 색**, 안쪽 글리프 = 자료 형식(글·링크·음성·사진·할일)
- **라벨** — 짧은 제목. 축소 시 7자, 확대 시 12자로 어절 경계 말줄임
- **새 별가루** — 최근 3개 중 안 열어본 것에 `NEW` + star 테두리 디밍 강조. 열면 해제
- **라벨 충돌 회피** — 정착 좌표로 판정(시드 좌표는 최대 179px 어긋난다). 북극성에 가까운 순으로 자리를 잡고, 이미 놓인 라벨이나 다른 노드 아이콘과 부딪히면 숨긴다. 선택·NEW는 항상 보임

### 8-4. 카메라
| 동작 | 규칙 |
|---|---|
| 팬 | 드래그 중 1:1 추적(보간 없음, 상태 갱신 없음 — transform만). 놓으면 관성(상한 14px/프레임, 감쇠 0.82 → 총 78px) |
| 줌 | 휠 → 목표 배율만 갱신, 지수 감쇠(EASE 0.24)로 추적. 커서 지점 고정 |
| 경계 | **노드 범위** 기준(중심점 아님) — 그래프가 화면에서 완전히 사라질 때만 막는다. 여유 80px |
| 원점 | 우상단 버튼 — 처음 배율·중심으로 |
| 좌표계 | `offsetWidth`(로컬 px) 기준 — `getBoundingClientRect`는 폰 프레임 스케일이 곱해져 어긋난다 |
| 성능 | 물리 정착 시 rAF 루프 정지. 값이 바뀐 요소만 DOM에 쓴다. 상시 드리프트 없음 |

### 8-5. 컨트롤
- **필터**(좌상단 y52, 높이 36) — 별·기간·태그
- **개수**(우상단 y52, 같은 기준선) — "18 별가루"
- **원점**(우상단 y96)

### 8-6. 튜토리얼 대화창
하단(탭바 위)에 위치. **첫 진입 3장** 안내(별자리 구성 → 조작 → 필터) 후 접혀서 우측 하단 작은 세컨비 단추만 남는다. 다시 누르면 안내 재개. 카드 밖 여백은 그래프로 포인터가 통과한다.

| KO 미성년 | 1388 청소년 + 109 |
| EN | 988 Suicide & Crisis Lifeline |

`tel:` 링크로 OS 다이얼러 위임. 고지 상시: "입력한 내용은 저장되지 않아요 · 횟수가 차감되지 않아요"

**트리거 6지점** — 세컨비 대화(전송 직전) · 담기 일기(저장 후) · 음성 전사(미노출) · 통화 녹음(전사 폐기) · 북극성 문장(저장 전) · 리즈닝 배치(1건이라도 red면 런 전체 중단 + 환불)

다른 화면에서 `env.openCrisis({locale, minor})`로 호출.

### 15-4. 법률 문서
`terms` · `privacy-policy` · `refund` — **한 화면 아코디언**('정책 및 약관'). 순서 고정: 이용약관 → 개인정보 처리방침 → 환불 및 청약철회 정책. 탭하면 펼치고 다시 탭하면 접는다. 펼침 후 그 자리로 스크롤. 본문은 절 구조만, 법무 원문 대기.

### 15-5. `/subscription` 구독 관리
플랜 카드 + 갱신일 + 결제수단. `구독 해지하기` → 모달(해지 / 지금 바로 해지 / 그대로 두기). `환불 요청하기` → 모달.

**환불 자격 없음도 산수와 함께** — "환불 가능 기간 7일 중 4일 남음 / 리즈닝 사용 3회(무료 기준 2회) / AI 호출 18건". bare no 금지.

### 15-6. 티어
**별바라기 · 항해자 · 북극성** (사용자 노출 명칭 확정)

## 16. 아바타 시스템 (64×64)

### 16-1. 자산 138종
| 종류 | 수 |
|---|---|
| 헤어 | 24 |
| 액세서리 | 20 |
| 얼굴 디테일 | 14 |
| 표정 | 10 |
| 동물 | 26 |
| 직업 | 44 (12개 분야) |

16×16에서 전량 이전. 64칸이라 명암(좌상단 광원) · 흰자·눈동자·반사광 분리 · 눈썹·코·입술 음영 · 볼 홍조 · 옷 소매·칼라가 들어간다.

### 16-2. 규칙
- 동물은 **종별 허용 털색**만(개구리 초록, 판다 흰색, 곰 갈색)
- 밝은 머리·털색이면 눈썹 최소 대비 보장
- 웃음 표정은 눈 상자를 먼저 얇게 잡고 그 안에 눈동자
- 직업은 모자·의상·소품까지(의사 청진기, 요리사 토크, 소방관 헬멧)
- **작은 칩(40px 이하)은 crop** — 머리 영역(12–52 × 0–40)만 잘라 한 칸 = 1px 유지
- 16 그리드 저장본은 인덱스 형식을 흡수해 그대로 보존(시드 재생성 안 함)

### 16-3. 아바타 스튜디오
프레임 안 전체 시트. 탭 3개(모양 · 직업 · 색). **바둑판 배열**로 스크롤 없이 훑고, 각 칸에 그림 + 이름. 선택 항목은 액센트 배경 + 체크 + 굵은 글자 + 1유닛 침하. 색 견본은 가운데 표식.

## 19. AI 뮤지엄 (`/museum`)

43개 전시(AI 발전사 + 세계 흐름). 각 전시에 **실제 사진**(위키미디어 공용 PD·CC). 1/4 크기로 그린 뒤 4배 확대(nearest-neighbour)해 픽셀 결을 화면과 맞춤. 사진 아래 출처·라이선스 표기.

**도판 탭 → 원본 팝업** — 제목 + 닫기 + 출처. 스와이프와 구분(8px 이동 초과 시 클릭 무시).

`focusId` 파라미터로 특정 전시를 열고 그 위치로 가로 스크롤(대화창 `보러가기` 연동).

## 20. 카피 원칙

### 20-1. 어휘 정책
어려운 말을 쉬운 말로 (47곳 전역 치환).

| 이전 | 현재 |
|---|---|
| 비준 | 확인 |
| 승인 이력 | 확인 이력 |
| 승인 / 보류 / 거절 | 맞아요 / 나중에 / 아니에요 |
| 검증틀 | 검사 |
| 파생 신호 | 분석 결과 |
| 온디바이스 우선 | 기기에서 먼저 |
| 열람 | 보기 |
| 근거 | 이유 |
| 한도 소진 | 다 썼어요 |

### 20-2. 제거 원칙
**당연한 것은 쓰지 않는다** — "생년월일은 공유하지 않아요", "연락처는 저장하지 않아요", "이미지를 보관하지 않고 학습에 쓰지 않아요" 등은 약관에 있을 내용이므로 화면에서 제거. 단 약관·처리방침·동의 항목 안내는 법적 명시가 필요한 자리라 유지.

### 20-3. 조사 처리
데이터에 따라 조사가 갈리는 문장은 자동 판정. 숫자는 읽는 소리(0·1·3·6·7·8 → 받침 있음), 한글은 음절 종성.
