## 설정 (`/settings`) — windowed
목적: 앱 전체의 컨트롤 타워. rev2 M3 토글 카드(모양·소식·구독·기능·데이터 연동)를 상단에, 계정·앱 내비게이션과 언어 선택, 단계형 데이터 삭제 위험 구역, 로그아웃을 하단에 배치한다. '플라시보 컨트롤 금지' 원칙: 실제로 동작하는 스위치와 정직한 이동 링크만 남긴다.

기능 · 필수 컨트롤:
- 다크 모드 스위치 → ThemeContext mode dark/light 전환(즉시)
- 공지사항 행 탭 → /notices push
- '요금제' 텍스트 버튼 → /plans push
- 구독 관리 행 탭 → /subscription push
- 리즈닝 행 탭 → /reasoning push
- 위키 자동 만들기 스위치 → 낙관적 토글 + setWikiAutoPromote(userId, next) 서버 저장(fail-soft)
- 연동 관리 / 전체 → /integrations push
- 파일로 가져오기 → /import-hub push
- 내 계정/앱 그룹 버튼 → 각 라우트 push (프로필·개인정보·계정·테마·데이터·기록·지원)
- 코치마크 리셋 → resetCoachmarks() 후 '/' replace — 홈 가이드 즉시 재생
- 언어 pill 탭 → i18n.changeLanguage(code) — 화면 언어 즉시 전환
- 삭제 스텝 pill 탭 → 해당 스텝의 삭제 버튼 묶음으로 하단 내용 교체(한 번에 한 영역)
- 각 삭제 버튼 → 확인 모달 → [삭제] 시 해당 벌크 삭제 실행, 성공 토스트 + 세컨비 머리 'sad' 표정, 실패 시 재시도 가능한 오류 모달
- 전체 데이터 삭제 (DELETE 입력 후) → 확인 모달 '마지막 확인: 모든 데이터가 사라집니다. 익스포트는 미리 받으셨나요?' → deleteAllUserData 실행 → 성공 토스트 → 0.9초 뒤 /capture replace
- 로그아웃 → signOut() → /sign-in replace; 실패 시 오류 모달

담아야 할 정보 묶음(구성 자유): 헤드라인 + 안내문 · 모양 (M3 토글 카드) · 소식 · 구독 · 기능 · 데이터 연동 · 작업 중 배너 (조건부) · 내 계정 (내비 그룹) · 앱 (내비 그룹) · 설정 2차 링크 (DeepSpaceLinks) · 언어 (접이식 disclosure) · 데이터 삭제 (위험 구역, 접이식) · 로그아웃 + 빌드 정보 · 오버레이

4-상태: empty: 해당 없음(설정은 항상 전체 렌더) / loading: auth 로딩 중 DeepSpaceScreen windowed 셸 안에 PremiumLoadingState '설정을 불러오는 중이에요…' / error: 삭제/로그아웃 실패 시 제품 톤 오류 모달(제목·본문·재시도); raw 에러는 콘솔에만 / filled: 전체 섹션 렌더; 삭제 작업 중엔 busy 배너 + 모든 파괴 버튼·로그아웃 비활성

게이팅(불변): auth: 미로그인 시 /sign-in Redirect · tier: 없음 · minor: 없음(이 화면 자체는) · consent: 없음
안전(불변): 삭제는 전부 확인 모달 + 전체 삭제는 DELETE 타이핑 게이트. 삭제 진행 중 이탈 방지 배너. 계정 정보·동의 이력·책임 기록은 전체 삭제에서도 유지됨을 명시.

## 요금제 (`/plans`) — windowed
목적: 페이월. 별바라기(무료)/항해자/북극성 3단 여정 카드와 정직성 카드('더 비싸다고 더 나은 나를 주지 않아요'), 법정 가격 고지, 리워드 광고 충전 진입(자격 시). 웹은 Paddle 체크아웃, 네이티브는 RevenueCat IAP. 엔타이틀먼트는 항상 서버(webhook)가 부여.

기능 · 필수 컨트롤:
- 항해자/북극성 시작 → 웹+Paddle 설정 시 openPaddleCheckout(tier, locale) — 티어 부여는 paddle-webhook 서버측; 네이티브는 RevenueCat purchasePackage → 성공 시 refreshTier()로 DB 티어 재조회
- 광고 행 탭 → RewardedSheet 오픈 → 시청 완료 시 addRewardCredits, 잔여 횟수 갱신 (COUNTS만, 품질 불변)
- 구매 복원 → restorePurchases() → 복원 결과 반영 + refreshTier(); 복원할 것 없으면 '복원할 이전 구매가 없어요.'
- 이용약관/환불 정책 → /terms, /refund push
- 문의하기 → /support push
- back → router.back()

담아야 할 정보 묶음(구성 자유): 헤드라인 · 정직성 카드 · 티어 카드 3장 · 가격 고지 + 법적 링크 · 결제 없이 늘리기 (조건부) · 스토어 안내 / 오류 / 복원

4-상태: empty: 패키지 0개(웹/미설정) → 티어 카드는 그대로, 하단 스토어 안내 카드 / loading: 스피너 행 '플랜을 불러오는 중이에요…' / error: '플랜을 불러오지 못했어요…' / '결제가 완료되지 않았어요…' / '구매를 복원하지 못했어요…' 붉은 중앙 텍스트 / filled: 3 티어 카드 + 현재 티어 pill + 고지 + (자격 시) 리워드 행

게이팅(불변): auth: userId 없으면 리워드·잔여 미조회(화면은 열림) · tier: 현재 티어 pill 표시; free 만 리워드 대상 · minor: 미성년은 리워드 광고 진입 자체가 숨김(fail-closed) · consent: ads 동의 없으면 리워드 숨김
안전(불변): 같은 품질 원칙 절대: 요금은 횟수·페르소나·보관만 차등. Pro는 구매 불가('준비 중'). 죽은 버튼 금지 — 결제 불가 상태는 안내 카드로 대체.
이동 대상: /terms, /refund, /support

## 구독 관리 (`/subscription`) — windowed
