## 오늘의 비서 (`/ops`) — windowed
목적: 개인 비서 축의 허브 화면. 오늘 할 루틴을 링(ring)으로 보여주고, 사용자의 기록(별가루)에서 뽑은 구체적인 '다음 걸음'을 LLM으로 추천받아 캘린더·공유 시트·루틴 저장으로 넘겨준다. 하단에는 일일 집중·리마인더·공유 카드 등 비서 도구로 가는 문이 모여 있다.

기능 · 필수 컨트롤:
- 루틴 행 탭 → 해당 루틴 오늘 완료 기록(logRoutineCompletion, ops_routine_logs). 링/카운트 즉시 갱신, 실패 시 롤백
- '돌리기' 탭 → router.push('/insights')
- 그룹 칩 탭 → 그룹 선택 + 도메인/추천/상태 초기화
- 도메인 칩 탭 → 전용 화면 도메인이면 router.push(해당 라우트), 아니면 domain 선택
- '다음 걸음 제안받기' 탭 → 미성년+recommendations OFF면 off 상태 문구, 일일 한도(free 3/soma 10/cortex 20/brain 50) 초과 시 limit 문구, 아니면 recommendForDomain LLM 호출 → 추천 카드 렌더 + 사용량 +1 + adherence 칩
- 추천 카드 '공유' 탭 → OS Share 시트 (제목+이유)
- 추천 카드 '캘린더에 추가' 탭 → Google Calendar 이벤트 작성 URL 외부 오픈 (제목·설명·시작시각·길이·반복 prefill)
- 추천 카드 '루틴으로 저장' 탭 → ops_routines에 루틴 생성 + scheduleRoutineReminder로 기기 알림 예약, 결과 토스트(설정됨/권한 꺼짐/실패/웹 불가) + 오늘 목록 리로드
- '리마인더' 버튼 탭 → router.push('/reminders')
- 도구 카드 탭 → 각 라우트로 push (/focus /reminders /imagine /share-card /srs /call-reflection)
- 뒤로가기 → router.back()

## 예약 리마인더 (`/reminders`) — windowed
목적: 리마인더 시간이 붙은 활성 루틴을 한 곳에서 보고, 항목별로 기기 알림을 켜고 끄는 가시성 화면. ON은 '실제로 OS 알림이 예약돼 있음'을 뜻하며(플래그+OS 스케줄 이중 확인), 내용은 기기를 떠나지 않는다.

기능 · 필수 컨트롤:
- 스위치 OFF→ON 탭 → OS 알림 권한 요청(propose→ratify: 탭이 곧 동의) 후 루틴 시간·반복으로 실제 예약. 거부되면 OFF 유지 + '권한 필요' 상태
- 스위치 ON→OFF 탭 → 예약된 OS 알림 취소 + 플래그 저장(AsyncStorage disabled-set)
- '오늘의 비서에서 추가' 탭 → router.push('/ops')
- 읽기 실패 시 '다시 시도' → 루틴 목록 리로드

담아야 할 정보 묶음(구성 자유): OpsFrame 헤더 · 정보 헤더 카드 · 리마인더 카드 리스트 · 푸터 CTA

4-상태: empty: 예약 루틴 0건이면 카드 없이 '예약된 리마인더 0개' 헤더 + 푸터 CTA만 (가짜 데모 행 금지) / loading: 루틴 로딩 중엔 리스트 미표시 / error: OpsState error: '잠시 불러오지 못했어요 / 네트워크를 확인해 주세요' + '다시 시도' / filled: 정보 헤더 + 리마인더 카드들 + 푸터

게이팅(불변): auth: useAuth userId 필요 (없으면 빈 목록) · platform: remindersSupported()=false(웹 등)이면 스위치 비활성 — 표시만

## AI 뮤지엄 (`/museum`) — museumLike
> [방향 변경] 2026-08-10 방향 (Simon 결정, 디자인 반영): 뮤지엄은 홈 별자리 슬롯에서 빠지고 홈 코너 버튼으로 진입한다. 화면에는 기존 2축 타임라인 위에 "최근 소식 · 트렌드" 스트립을 신설한다 — AI 최신 소식 카드(가로 캐러셀) + 주간 트렌드 요약. 데이터 소스는 정적 캐논 확장 또는 운영 발행 중 결정 필요(인앱 공지 파이프라인과는 분리 유지).

## IDEN · 포터블 정체성 (`/iden`) — windowed
목적: 축적된 자기 이해를 휴대 가능한 `.iden` 파일(AI가 읽는 절반)과 한 장짜리 CV 시트(사람이 읽는 절반)로 내보내는 화면. 무엇을 담을지 4개 카테고리 토글로 사용자가 통제하고(데이터 주권), Markdown/JSON/PDF 형식으로 내보내거나 외부 AI(ChatGPT·Claude·Gemini·Notion)에 전달한다.

기능 · 필수 컨트롤:
- 토글 탭 → excluded 목록 갱신 — 해당 카테고리의 실제 필드 키들이 모든 내보내기에서 드롭
- 형식 칩 탭 → fmt 상태 변경 (Markdown/JSON/PDF)
- '내보내기' 탭 (Markdown) → exportIden 실행 → .iden 텍스트를 OS Share 시트로
- '내보내기' 탭 (JSON) → exportIden → JSON을 클립보드 복사 + 'JSON을 복사했어요' 알림
- '내보내기'/'미리보기' 탭 (PDF/시트) → 웹이면 새 탭에 CV 시트 HTML 오픈(인쇄→PDF), 네이티브면 '미리보기 시트는 웹에서 열려요'
- AI 타겟 카드 탭 → router.push('/integrations')
- 빈 상태 CTA '담으러 가기' 탭 → router.push('/interview')
- 에러 상태 '다시 시도' 탭 → buildIdenDoc 재시도
- 뒤로가기 → router.back()

## 공유 카드 (`/share-card`) — windowed
목적: 자기 이해를 1080×1080 정사각 카드 한 장으로 만들어 저장·공유하는 화면. A(통찰 카드: 북극성 문장 한 줄)·B(별자리 카드: 7도메인 점 + 북극성 코어) 두 변형을 미리 보고 OS 공유 시트로 내보낸다. 프라이버시 계약: 카드에는 문장 1개 + 별 개수 + 별가루(조각) 수만 담기고 원문·수치·핸들은 제외.

기능 · 필수 컨트롤:
- 변형 칩 탭 → A/B 프리뷰 전환 (캡처 호스트도 동기화)
- '이미지 저장' 탭 → 1080 캡처 → OS 내보내기 시트(사진 저장/다운로드 노출). 진행 중 '저장 중…' + 양 버튼 비활성
- '공유' 탭 → 1080 캡처 → OS 공유 시트 (핸들은 공유 텍스트에만). 진행 중 '여는 중…'
- 로드 실패 화면의 '다시 시도' 탭 → 도메인 레벨 재로딩

목적: Margolis, Schwitzgebel, Ozer & Lyubomirsky (2019)의 무료 6문항 자기보고로 삶 전체에 대한 만족을 직접 측정하는 검증 도구 화면. 결과는 AI 호출 없이 note 레코드로 저장되어 /persona에서 다른 검증 도구들과 함께 표시된다. 별자리의 밝기(자기 이해 정도)와는 별개 구성개념.
