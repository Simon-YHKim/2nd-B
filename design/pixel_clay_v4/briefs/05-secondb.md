## 세컨비 (`/secondb`) — windowed
목적: 세컨비(2nd-B) 캐릭터와의 메인 AI 대화 화면. 사용자의 위키/기록을 RAG 근거로 삼아 답하고, 참고한 별가루(위키 페이지) 인용 칩을 함께 보여준다. rev2 3-페르소나(2nd-B 공감 / 메타비 객관 / 트위비 상상)가 한 대화 맥락을 공유하며, 선택한 페르소나의 액센트 색으로 화면 전체가 틴트된다.

기능 · 필수 컨트롤:
- 메시지 전송 (버튼/Enter) → user 턴 추가 → sendChatMessage(C9 분류 → callGemini → C3 감사로그) → 답변 파싱(인용 칩 + 트위비 갈래) → usedToday 갱신. blocked면 힌트 synthetic 턴 + 리워드 시트(자격 시) + 안전 소프트스톱 비트
- 렌즈 버튼 탭 → 페르소나 전환(트위비=Divergent 모드), 화면 틴트 변경. 잠금 렌즈면 /plans?from=persona_<id>
- 퀵액션 칩 탭 → 컴포저 프리필 (새 관점으로 = 트위비 전환 포함), 사용자가 직접 전송
- 답변 버블 롱프레스 → 클립보드 복사 + 캡션/스크린리더 공지
- 근거 칩 탭 → 참고 별가루 서랍 오픈
- 서랍 카드 탭 → /wiki?focusPageId=<id> 이동 (해석 실패 시 /wiki)
- 트위비 갈래 칩 탭 → 갈래 텍스트 컴포저 프리필
- 갈래 '담기' 탭 → /capture?text=<갈래> 이동
- 마이크 탭 → 권한 요청 → 녹음 시작; 재탭 = 정지 + 전사 → 드래프트에 이어붙임 (임시 오디오 파일은 전사 후 즉시 삭제)
- '지우기' 탭 → 현재 대화 비움 (로컬만; 히스토리 미영속)
- '플랜 보기' 탭 → /plans?from=ai_limit
- 인트로 모달 '오늘은 그만 볼래요' → 오늘(KST) 동안 재표시 안 함 (기기 저장)
- 리워드 시트 시청 완료 → grantChatAdBonus RPC → 오늘 허용량 +2, 다음 전송이 재판정

담아야 할 정보 묶음(구성 자유): 페르소나 배너 (헤더) · 노드 컨텍스트 필 · 메시지 리스트 · 퀵액션 칩 행 · 한도 링크 · 페르소나 토글 (렌즈 3분할) · 입력 바 (컴포저) · 첫 진입 인사 모달 · 참고 별가루 서랍 (바텀시트) · 오버레이

## 리즈닝 (`/reasoning`) — windowed
목적: 담아둔 기록·자료를 최대 5개 선택해 세컨비가 7개 생활 도메인 별(커리어·재정·성장·관계·건강·휴식·담아내기) 중 하나로 잇는 명시적 딥런 화면. 결과는 제안(proposal)으로만 나오고 사용자가 비준(ratify)해야 도메인 태그가 붙고 별이 밝아진다. 주간 한도(무료 2회, 월요일 00:00 KST 리셋)와 자동 리즈닝 토글을 함께 관리한다.

기능 · 필수 컨트롤:
- 항목 탭 → 선택 토글 (최대 5개; running 중 비활성). done 단계에서는 반영할 제안 선택 토글
- '선택한 N건 리즈닝' 탭 → reserveRun(0092 원자적 예약) → 안전 스캔(classifyInputAnyLocale, 레드존이면 전체 중단+위기 시트) → callGemini(purpose reasoning_connect, pro 모델, JSON 스키마) → 제안 서버 영속(completeRun) → done. 실패/취소는 런 환불
- running 중 CTA '실행 취소' → abort + cancelRun(환불) + idle 복귀
- running 중 Back → 백그라운드 전환(글로벌 태스크 독 진행 표시) 후 뒤로; 완료 시 토스트로 복귀 안내
- done CTA '선택한 N건 반영' → ratifyProposals(선택=ratified, 미선택=dismissed, exactly-once) → 각 제안 apply(도메인 태그 + reasoning:ratified 태그 기록/소스에 기록, 소스는 위키 페이지 승격 best-effort) → markProposalApplied → 도메인 레벨 캐시 무효화(별 즉시 밝아짐) → idle
- 자동 리즈닝 스위치 첫 ON → AutoReasoningIntroSheet 확인 후 활성화; 이후 ON/OFF 즉시. 자동 런은 주간 베이스만 쓰고 마지막 1회는 수동용으로 보존, 리워드 크레딧은 수동 전용
- 소진 상태 CTA/광고 버튼 → ReasoningLimitSheet 오픈 (선택 유지)
- '플랜 보기' → /plans?from=reasoning_limit
- 화면 재진입 (제안 미처리 상태) → recoverStaleRuns(고아 런 환불) + listPendingProposals → 검토 상태 복원 (기기 전환·앱 킬 생존)

담아야 할 정보 묶음(구성 자유): 상단 앱바 (셸 타이틀) · 한도 소진 카드 (depleted 시) · 자동 리즈닝 카드 · 쿼터 카드 (idle) / 진행 카드 (running·done) · 자료 리스트 (FlatList) · 하단 고정 실행 바 · 시트·오버레이

4-상태: empty: '아직 담은 자료가 없어요' + '첫 자료 담기' CTA / loading: 리스트 로딩 '자료를 불러오는 중이에요'; auth 로딩 InlineLoader / error: '별을 잇지 못했어요. 잠시 뒤 다시 시도해 주세요.' / '백그라운드 리즈닝을 마치지 못했어요…' 에러 카드 + phase error / filled: idle(선택) → running(궤도 링) → done(제안 검토) → 반영 후 idle; depleted는 소진 카드

안전(불변): 배치 전 텍스트 전수 안전 분류(레드존 1건이면 런 전체 중단 + 환불 + CrisisRouter). LLM 입력은 sanitizeUntrusted + UNTRUSTED 펜스. 제안은 서버 영속 + exactly-once 상태 전이(0092) — 크래시로 런이 소모만 되고 결과가 사라지는 일 없음. 취소/실패 런은 소진 안 됨(DESIGN.md §6). '더 비싸도 더 나은 나를 주지 않는다' — 플랜은 횟수만 다름.
이동 대상: /plans, /capture, /sign-in, /complete-profile

## 연결 찾기 (`/research`) — windowed
목적: 흩어진 기록들 사이의 연결(태그 군집·허브·뜻밖의 연결)을 보여주는 지식 그래프 요약 화면. 기록의 태그 겹침만으로 $0 순수 계산하고, 별도로 AI가 제안한 의미 연결(inferred links)을 propose→ratify로 승인/거절한다. 딥스페이스 브랜치 = DeepSpaceResearchScreen.

기능 · 필수 컨트롤:
- 군집 칩 탭 → 하이라이트/포커스 라벨 토글
- 헤드라인/뜻밖의 연결 카드 탭 → /record/[id] 이동
- 'AI 연결 제안 받기' → backfillEmbeddings(배치) → proposeAllRelatedLinks → 제안 재로딩
- 제안 '승인' → ratifyLink 영속 + wink 표정 + '연결을 확정했어요' 공지 + 목록 갱신
