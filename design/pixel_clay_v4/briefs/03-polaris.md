기능 · 필수 컨트롤:

## 승인 이력 (`/ratifications`) — windowed
목적: propose→ratify 원장의 열람 화면. 별자리 밝기(별 레벨)에 반영된 모든 변화를 관측 기록(star_tier_history)에서 최신순으로 보여준다. 자동 반영은 존재하지 않으므로 영속된 기록은 전부 '승인'이며, 보류/거절 열은 정직하게 0.

기능 · 필수 컨트롤:

- '변화 없는 재계산 …' 토글 → 동일 레벨 재기록 항목 표시/숨김
- 빈 상태 '북극성으로 가기' → router.replace('/core-brain')

## 가치관 (`/values`) — windowed
목적: Layer B '가치관' 축의 자기보고 + 결과 열람 화면. 저장된 결과가 없으면 12문항 6점 리커트 가치 자기보고(Schwartz 이론 착안)를 제공하고, 결과가 있으면 공유 AxisCheckScreen이 CORE VALUES 상위 3 + 6바 가치 스펙트럼을 렌더한다. 진단이 아닌 자기보고 추정임을 항상 고지.

기능 · 필수 컨트롤:
- 인트로 '시작' → 설문 시작
- 인트로 취소 → 미측정 AxisCheck 상태 ('아직 측정 전이에요' + '인터뷰를 마치면 내 기록을 바탕으로 여기에 채워드려요.')
- 리커트 선택 → 실시간 scoreValues 채점
- 제출 → createRecord(tags:['values','assessment'], body=응답+점수+confidence JSON, topic='가치 자기보고', conclusion='자기보고 추정 (진단 아님).') → 저장 축하
- 저장 축하 완료 → 첫 별이면 /secondb?fromNode=가치 자기보고 (활성화 넛지), 아니면 결과 화면 재로드
- 설문 중 back(하드웨어/앱바) → 종료 확인 모달 (답변 유실 방지 게이트)

## 남이 보는 나 (지인 응답 랜딩) (`/peer/[token]`) — fullscreen
