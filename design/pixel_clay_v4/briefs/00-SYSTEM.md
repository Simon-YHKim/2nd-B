# 2nd-Brain 디자인 시스템 · 공통 규칙 (항상 이 파일을 먼저 읽을 것)

## 제품
- AI 시대 가장 가치있는 자산 = 나 자신. 데이터 축적(알아가기) → 개인 비서(세컨비) → 공상 구체화. 임상·의료 앱 아님, 나라는 자산을 만드는 생산 도구.
- 3축: 알아가기(도메인 별 점등) · 개인 비서(북극성→세컨비) · 공상→구체화(트위비 + propose→ratify).

## 개념 모델 (불변)
- 3-레이어 별자리: A 입력 = 7 데이터 도메인(홈에는 커리어·재정·성장·관계·건강·휴식 6별, 담아내기는 비가시) → B 검증 = 심리구인(절대 별로 렌더 금지) → C 출력 = 북극성(종합 페르소나).
- 시각 위계: 북극성이 항상 최대 크기·최대 글로우로 지배. 어떤 별도 북극성과 같아질 수 없다. 링크는 전부 cyan. 7번째 슬롯 = 커뮤니티 별(포탈, 밝기 없음, 2026-08-10 결정), 뮤지엄 = 홈 코너 버튼.
- 밝기 정직성: 별 빛 = 내가 넣은 만큼(L1~L5 DIKW: L1 꺼짐 / L2 1~4건 / L3 5~14건+분류 / L4 15건+ 또는 검증도구 / L5 비준만). 빈 상태는 정직한 0. AI는 비준 전에 별을 밝힐 수 없다.
- propose→ratify: AI 출력은 전부 제안. 자동 실행·자동 반영 없음. 사용자 승인만이 쓰기를 만든다.
- 세컨비 = 캐릭터 하나 + 3렌즈: 세컨비(2nd-B, #A78BFA, 공감, 무료) · 메타비(Meta-B, #46B6FF, 객관, 항해자+) · 트위비(Twi-B, #CFC4E8, 상상/Divergent, 북극성). 다른 캐릭터 도입 금지.
- AI 4표면 역할: 세컨비=물어보기(대화) · 리즈닝=담은 것 깊이 분석(주간 쿼터, 제안 생성) · 인사이트=자동 집계 요약 · 연결 찾기=기록 사이 다리 제안. 각 화면 상단에 역할 명찰 1줄.

## 디자인 토큰 (cyan-dark 기본 · 이 값만 사용)
- 캔버스 390x820 · 다크 기본 · 상태바 실제 시각, immersive에서 #CCFAFF
- 팔레트: primary #86CFFF / onPrimary #00344C / primaryContainer #004C6D / secondaryContainer #374955 / tertiary #D4BBFF(세컨비 보라) / surface #0B0F14 / onSurface #DEE3E8 / onSurfaceVariant #C1C7CE / surfaceContainerLow #131820 / surfaceContainer #171D25 / surfaceContainerHigh #222833 / outline #8B9298 / outlineVariant #41484D / error #F2B8B5
- 딥스페이스 액센트(팔레트 불변): 별 #CCFAFF · 별 코어 #46B6FF · 흐린 별 #7FC9F0 · 북극성 #C8B6FF(soft #D6C4FF) · 무드 긍정 #5FF0C0/중립 #A78BFA/부정 #FF7A90 · 말풍선 #091428 (at .95) 텍스트 #A7E0FF · 알림점 #FF8A5B
- 타이포: Pretendard(한국어) + Roboto(라틴) + Roboto Mono(숫자·코드·타임스탬프). M3 타입 스케일. 픽셀 폰트·Inter 금지.
- Shape: 4/8/12/16/28px 스케일, 버튼만 pill(9999). 칩은 radius 8(필 칩 금지).
- 모션: standard cubic-bezier(0.2,0,0,1) · 150~400ms. bounce/elastic 금지, reduced motion 존중.
- 레이아웃 3분류(셸 계약 — 화면 내부 구성은 자유): immersive(별하늘 위 풀블리드: 홈·위키그래프) / windowed(하늘 여백 12/12/14 안 radius 24 창 + 림 rgba(150,180,230,.16): 대부분) / museum-like(풀블리드 + 상단 스크림+앱바: 뮤지엄·별 렌즈).
- NavBar 5탭 고정: 별자리(/) · 담기(/capture) · 세컨비(/secondb) · 위키(/records) · 설정(/settings). 높이 80, 활성 pill 64x32. Material Symbols Rounded.
- 컴패니언 헤더(세컨비 머리 48px + 말풍선 radius 4/14/14/14)는 담기·세컨비·위키에만. 홈은 대형 머리 1개. 그 외 화면은 헤더 없음.
- 금지: 글래스모피즘 · 필 칩 · 장식 이모지 · bounce 이징 · 임의 hex(토큰만) · 4색 이상 · 화면당 시맨틱 컬러 3개 초과.

## 공통 UX 규칙
- 화면당 핵심 메시지 1 + 그래픽 1. 상세는 탭 뒤로(progressive disclosure). 한 탭은 화면을 단순화. 노드 위 모달 금지, Back은 화면당 한 곳.
- 모든 화면 4-상태 필수: empty(정직한 0 + 다음 행동 유도) / loading(세컨비 헤드+스피너, 스켈레톤 없음) / error(정직한 사유 + 재시도) / filled. 해당 시 depleted(쿼터 소진)·minor(미성년) 추가.
- 터치 타깃 ≥44dp. 한국어 클리핑 주의. i18n KO/EN 패리티.
- 쿼터: 채팅 별바라기 일5 / 항해자 일80 / 북극성 일250 · 리즈닝 주2/주7/무제한. 위기 라우팅·비준은 미차감. 잠긴 기능은 죽은 끝 없이 /plans로. "더 비싸다고 더 나은 나를 주지 않아요."
- 안전: AI 표면엔 위기 라우팅 상태 존재(핫라인 안내, KO 성인 109/미성년 1388+109/EN 988). 임상·병리 어휘 금지 — 자기 이해·성장·점검 프레이밍.
- 백그라운드 작업 비차단: 하단 작업 도크 + 완료 토스트(액션 포함). 자동 화면 이동 없음.

## 디자인 자유도 계약
- 고정: 각 화면의 목적 · 기능/필수 컨트롤과 동작 결과 · 고정 카피(글자 그대로) · 4-상태 존재 · 게이팅/안전 · 이동 대상 도달 · 위 토큰/위계/금지사항.
- 자유: 화면 내 배치 · 구성 순서 · 그루핑 · 컴포넌트 선택(M3 범위) · 시각 강조 · 여백 · 접기/펼치기 · 빈 상태 연출 · 마이크로 인터랙션(모션 토큰 내).
- 지시: 기능·카피·불변식이 지켜진다면 화면의 생김새는 네가 가장 좋다고 믿는 형태로 설계하라. 기존 앱 배치를 따라할 의무 없음. 목표는 더 명료하고 딱 봐도 알 수 있는 화면.
