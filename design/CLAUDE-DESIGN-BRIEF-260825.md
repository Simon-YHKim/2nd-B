정본으로 삼아 **겹치는 화면은 갱신하고, 없는 화면은 새로 만들어 달라.**

### 1. 그 사이 무엇이 바뀌었나 (네 번들에 반영 안 된 것)

**홈 별 일곱의 정체가 통째로 바뀌었다 (2026-08-24, "일곱은 한 벌").**

- 예전(네 번들): 홈 별 = 생활 도메인 (커리어·재정·성장·관계·건강·휴식) + 7번째 별 논쟁
- 지금: 홈 별 = **나를 알아가는 자리** — ① 프로필 ② 영유아기(0~6) ③ 학창시절(7~19)
  ④ 20대 ⑤ 30대 이후 ⑥ 직장 ⑦ 지금. 별자리 모양(북두칠성 좌표·선)은 그대로.
- 생활 도메인 여섯은 별에서 내려가 **세컨비 대화창 안 대시보드**("내가 아는 너" 패널)가
  됐다. 진입 = 별자리에서 세컨비 머리 터치.
- 별을 탭하면 인터뷰로 바로 가지 않고 **그 별의 요약 화면(`/me/<star>`)이 먼저** 열린다
  (지금까지 판 것 + 이어서 파기 CTA).
- 밝기 = 그 별에서 다섯 층(사실→감정→의미→믿음→메아리) 중 몇 층을 팠는가. L4 가
  자동 상한, **L5 는 사용자 비준으로만** 열린다.
- 살지 않은 시기 별(예: 스물다섯에게 "30대 이후")은 잠겨서 어둡다.

### 2. 발주 범위

**A. 갱신 (기존 시안이 있으나 구조가 낡음) — 우선순위 순:**

1. **홈 별자리** (네 캡처 01) — 별 일곱의 이름·의미 교체(위 새 일곱). ⚠ 네 번들의 보라
   "커뮤니티" 별은 이식 금지 — 7번째 별은 커뮤니티가 아니라 **프로필**이다. 살지 않은
   별의 잠금 상태(어둡게+자물쇠 없이 시각적으로만) 표현 추가.
2. **세컨비 대화** (캡처 03) — 대화창 상단에 펴지는 **생활 여섯 영역 대시보드 패널**
   ("내가 아는 너": 영역별 L1~L5 등급 막대, 접기 버튼, 행 탭 → 도메인 상세) 신규 상태 추가.
3. **별 요약 `/me/<star>`** — **신규 화면.** 별 이름 + 시기(나이 경계) + 판 층 진행 +
   빈 상태("아직 아무것도 없어요") + 시작하기/이어가기 CTA. 잠긴 별 상태 포함.
4. **인터뷰 `/interview`** — 5층 드릴다운 대화 + 대화가 끝난 뒤에만 보이는 진행판
   (시기×층 행렬). "모르겠다" 발판 상태(같은 층에서 더 쉬운 질문) 반영.
5. **밝기 변화 `/brightness`** — 8주 히트맵(새 일곱 별 행) + 빈 상태.
6. **비준 `/review`** — 검사 기반 후보(기존) + **시기 별 후보**(새로: "학창시절" 등 별
   이름 버튼 → 제안 시트: before/after/근거 기록 목록/승인·보류) 두 그룹.

**B. 신규 (시안이 아예 없음):**

7. `/people` — 관계 인물맵 (나를 중심으로 친밀도 궤도에 인물 배치)
8. `/rest` — 재충전 활동 want/active/done 3상태 보드

### 3. 시각 계약 (PIXEL-CLAY v4 — 네가 만든 규칙, 전부 유지)

절대 규칙 7: ① 도형은 정수 좌표 `rect` 만 ② border-radius 0 ③ blur 금지 → 디더 스크림
④ 정적 opacity 금지 → 색 밴딩/50% 디더 ⑤ 모션은 `steps()` 이징만 ⑥ 입체는 4방향 베벨
⑦ 색은 토큰만. 폰트 = Galmuri 4종(14/11/9/Mono11). 팔레트 = **midnight 고정**
(--bg #0a0e18 · --panel #141b2e · --accent #5b8def · 딥스페이스 브랜드층 --ds-core
#46B6FF · --ds-polaris #C8B6FF 등). 단위 **--u = 2px 고정** (네 캡처 12장은 4px
데스크톱이라 실제 폰의 2배 크기다 — 새 시안은 더 촘촘해야 정상). 별 모양 = rect 이되
**"4방향으로 빛나는 별 모양"**(12셀 짝수격자 rect 4장 + 디더). 디더는 작은 타일 이미지
반복으로 구현 가능해야 한다. hover 상태는 만들지 말 것(터치 앱) — `:active` 의
`translateY(var(--u))` press 만.

### 4. 지켜야 할 개념 (불변)

별자리·북극성(항상 최대 밝기, 일곱보다 지배적)·정직한 밝기 L1~L5(부풀리기 금지, 빈
상태는 빈 대로)·propose→ratify(AI 는 제안만, 승인은 사용자)·화면당 메시지 하나+그래픽
하나·터치 타깃 44px·reduced-motion 대응. **금지 어휘**: 임상 용어(치유·상담·진단 등),
"렌즈"(사용자 표면에서 퇴역한 내부 용어). 세컨비 호칭은 그대로 세컨비(개명 보류 중).

### 5. 산출 형식

이전 번들과 같은 구조로: 화면별 JSX 프로토타입 + 실측 캡처(이번엔 --u=2px, 390px 폰
뷰포트) + 바뀐 결정을 적은 노트. 우리가 인수 검증 때 네 번들과 저장소가 어긋난 곳을
6건 찾았으니(7번째 별=프로필이 대표), 이번에는 **PRD v4 와 어긋나는 것을 발견하면
임의로 조정하지 말고 노트에 질문으로 남겨 달라.**
