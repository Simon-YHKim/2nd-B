## 구현 경계

- 기기 위기 검사가 확인 UI보다 먼저다. 계속을 선택해도 전송의 위기 검사를 다시 통과해야 한다.
- 확인 중에는 기존 입력·전송·주제 변경 동작을 표시하지 않는다. 이미 큐에 든 전송·주제 변경도 ref로 차단한다.
- 선택은 ref에서 먼저 소비한다. 중복 탭과 이전 확인의 버튼 callback이 다른 답을 끝내거나 보내지 못한다.
- 계정 lease·epoch·언어·시기·미성년 상태·화면 생존·종료 상태를 확인한다. 계정이 바뀌면 세션 key도 바뀐다.
- 화면 뒤로, Android/폰 내부 뒤로, 네이티브/브라우저 GO_BACK·POP은 계속과 같다. 인증 RESET 등 다른 제거는 답을 보내지 않고 원래 navigation action을 보낸다.
- `continuedAfterStop`은 세션 메타데이터다. 종료 해석만 넘기며 안전·답 길이·불확실함·모델의 층 판정을 건너뛰지 않는다. 모델 지시문과 저장 대화 문자열에 추가하지 않는다.
