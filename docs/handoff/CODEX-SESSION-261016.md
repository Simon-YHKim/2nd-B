## 재개 방식

먼저 `docs/HANDOFF.md` 최신블록과 전체원장·PENDING을 읽는다. 미병합코드는 증거페이지의 incremental git bundle에서 복원하며, 현재main 히스토리를 먼저 가져온 뒤 해시를 확인한다. 정확 커밋과 원BLOCK이 이어져야 한다. 작성자검사만 있는 S2b/C3/P를 PASS로 간주하지 않는다. 로컬절대경로가 새환경에 없으면 복구묶음의 scratch/README와 원본SHA를 이용한다.

이 인수는 [simon-handoff skill](https://github.com/Simon-YHKim/SimonK-stack/blob/1a4a4239d1e3acbc81998f17db4950ec5c5111be/skills-src/simon-handoff/SKILL.md)에 따른다. docs/HANDOFF는 디스크·Git·main에 보존하며, 과거본문을 삭제/요약하지 않고 색인을 맨위로 옮기고 Latest마커를 하나로 정리한다. 활성/보관400KB한도와 원문보존검사를 실행한다. 다음세션이 GitHub만으로 현재목표와 위험·다음순서를 이해할 수 있고, 비공개복구묶음으로 미병합코드/실패원증거까지 이어받도록 구성했다.
