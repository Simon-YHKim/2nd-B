GA4 웹 전환 이벤트 계약

2026-09-25 · 구현 및 로컬 검증 계약. 운영 전송·결제·배포는 실행하지 않음.

4개 웹 전환 · 성인과 선택 동의 필수 · Sandbox 전송 차단

외부 분석 동의를 서버에서 확인한 웹 세션만 관측한다. 동의 전 이벤트를 보관하거나 이후 동의에 맞춰 재생하지 않는다. 결제 권한 부여는 Paddle 웹훅이 담당한다.

실제 성공 지점과 허용 값

이벤트시점허용 필드
login이메일 인증과 AuthContext refresh 성공, 기존 프로필의 명시적 웹 OAuth 콜백 성공, 또는 기존 계정의 가입/프로필 완료 성공. 세션 복원·토큰 갱신·탭 복귀는 제외.method: email/google/apple/kakao/naver/facebook/github

동의 확인과 계정 전환
  • AuthContext의 서버 연령 판단과 새 서버 DOB 조회가 모두 성인이라고 확인해야 한다. 알 수 없는 연령·미성년·조회 실패/5초 시간 초과는 차단.
  • 기존 동의를 읽는 중인 상태와 이미 확정된 OFF를 구분한다. 인증 성공 관측은 같은 계정의 진행 중 조회만 기다린다. 확정 OFF는 재조회로 덮어쓰지 않는다.
  • 계정 epoch 전환 시 React 화면 반영 전에 즉시 동의를 해제한다. 서버 조회 중 철회, 계정 변경, OFF→ON이 일어나면 이전 관측을 버린다.
  • SDK 준비 대기 큐는 이미 동의한 이벤트만 사용한다. 철회 시 폐기하며, 확인된 runtime OFF에서 재조회 중이어도 큐에 넣지 않는다.
  • 네이티브 Firebase/Clarity와 웹 Clarity는 기존 하드 OFF를 유지한다.
Paddle 금액·개인정보·중복 계약
  • Callback 전체를 GA에 전달하지 않는다. 구매용 새 객체를 허용 목록으로 만든다. customer/email/payment/custom_data/서명/사용자 ID는 분석 필드에 포함하지 않는다. nonce는 결제 모듈 내부의 동일 시도 확인에만 사용한다.
  • 허용된 단일 plan price와 quantity=1을 확인한다. Paddle.js 금액은 통화 단위 number이다. API의 최소 화폐 단위 문자열로 해석하거나 100으로 나누지 않는다.
  • value=subtotal-discount로 세금을 제외한다. item 금액과 일치해야 한다. 음수·문자열·NaN/Infinity·지원하지 않는 ISO 통화·잘못된 통화 소수 자리는 거절한다.
  • 동의가 있는 상태에서 열린 production checkout만 관측한다. 그 뒤 철회/계정 전환이 발생하면 해당 시도의 callback은 영구 폐기한다. sandbox는 전송하지 않는다.
  • transaction ID는 현재 문서 수명 동안 최대 1,000건의 메모리 집합으로 중복을 막는다. SDK 큐에 수락한 구매도 포함한다. 저장소에 계정 ID·PII·이벤트를 쓰지 않는다. 재로드를 가로지르는 클라이언트 중복 제거는 보장하지 않는다.
검증과 운영 확인

로컬 Jest는 실제 analytics 모듈에 가짜 Supabase 조회와 가짜 gtag/SDK를 연결한다. 허용 필드 누출 RED, 동의 경합·거부·계정 전환·콜백 중복·금액 검증·sandbox·인증 성공 이후 순서·실패 뒤 미발행을 검사한다. 실 GA DebugView나 결제 샌드박스에 전송한 검증은 아니다.

프로필 조회 실패로 연령이 미해결인 경우는 임시 중단이며 명시적 OFF가 아니다. 같은 계정의 조회 재시도로 성인이 확인되면 기존 서버 동의를 다시 확인한다. 중단 중 버린 이벤트는 재생하지 않는다.

웹 OAuth의 method는 서버 계정의 app_metadata.provider를 사용한다. 여러 로그인 identity를 연결한 계정에서는 이번 인증 수단과 다를 수 있으며, email 원계정의 OAuth 로그인은 보수적으로 누락될 수 있다. 해당 경우의 정확한 분류에는 별도의 provider 연결 증거가 필요하다.

배포 후 권한 있는 운영자가 동의한 성인 테스트 세션에서 GA4 DebugView의 이벤트/허용 필드를 확인하고 필요한 Key events를 설정해야 한다. 실제 결제 상태는 서버 웹훅과 별도로 대조한다.
