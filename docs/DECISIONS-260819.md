### D1. 북두칠성 → 북극성 연결선

**⚠ 전제 정정: 그 선은 이미 화면에 그려지고 있다.**

`ConstellationHome.tsx:85,646` 이 `finance(230,131) → career(228,90) → POLARIS(140,-16)` 을
점선(2k on / 5k off, 45% 알파)으로 그린다. 좌표가 캐논 `polarisGuide` 문자열과

없는 것은 선이 아니라 **연결**이다. `canonPolarisGuide` 상수를 읽는 코드가 0건이고,
파리티 테스트도 별 좌표만 보고 선은 안 본다. 즉 **캐논과 화면이 따로 논다** —
캐논에서 선을 고쳐도 화면은 안 바뀐다.

> **권고**: 시안을 새로 그릴 것이 아니라 `ConstellationHome` 이 `canonPolarisGuide` 를
> **읽게** 하고 파리티 테스트에 선을 추가한다. 그러면 캐논이 선에 대해서도
> 검증 가능한 주장을 하게 된다.

### D2. 대화 자동저장 기본값

**⚠ 전제 정정: 자동저장은 이미 있다.** #1236 (2026-08-18) 이 넣었다.

| | |
|---|---|
| pref 키 | `chat_autosave` (`privacy_prefs` jsonb) |
| 기본값 | **OFF** (fail-closed) |

> **권고**: 기본값 OFF 유지(`privacy/prefs.ts` 규율 · PIPA). 대신 대화 화면에서

### D4. `digest` 이름 혼동

**네 가지가 같은 단어를 쓴다.** 실측:

| 이름 | 무엇 | 상태 |
|---|---|---|
| 라우트 `/digest` | **"오늘의 정리"** — 일일 propose→ratify 리뷰. LLM 안 씀 | 살아 있음 |
| 캐논 `screens.json` 제목 | **"주간 다이제스트"** | **화면과 다르다 (틀렸다)** |
| LLM 좌석 `digest_weekly` | 주간 2신호 인과 패턴 | **호출처 0건** (죽은 좌석) |
| `news_digest` | `/ops` 의 뉴스 요약 도메인 | 무관 |

게다가 "오늘의 요약" 에 해당하는 **AI 기능은 `digest` 가 아니라 `ops_daily_brief`** 이고,
실제 테이블(`ops_daily_brief`)도 그쪽에 있다. 즉 **"digest" 라는 단어가 AI 가 아닌 쪽을
가리키고 있다.**

> **권고**: 세 단계. ① 캐논 제목을 "오늘의 정리" 로 고친다(즉시, 무비용).
> ② `digest_weekly` 는 호출처가 0이므로 **살릴지 지울지 결정**한다 — DB enum 에
> 들어 있어 지우려면 마이그레이션이 필요하다. ③ 라우트 이름 `/digest` 자체는
> 그대로 둔다(딥링크·i18n 네임스페이스가 걸려 있어 개명 비용이 크다).

### D5. 밝기 L1~L5 계산 기준

**⚠ 전제 정정: 이미 결정돼 있고 코드가 정본이다.** PRD 가 "검증도구 1개=L4 여부 미확정"
이라고 적은 것은 **프로토타입이 저장소를 몰랐던 것**이다.

`src/lib/persona/brightness.ts`:

```
source = default        -> L1
source = questionnaire  -> L4     ← 검증도구 1개 = L4. 이미 그렇다
source = journal_text   -> high L4 / medium L3 / low L2
crossSourceAgreement    -> +1 (최대 5)
ratified                -> L5     ← L5 에 이르는 유일한 길
brightnessFraction      = level * 0.2   (20/40/60/80/100%)
```

관측 수 기준은 `domain-confidence.ts`: `>=15` high · `>=5` medium · 그 미만 low.

> **권고**: 저장소 규칙을 정본으로 확정하고 PRD 쪽을 맞춘다. 새로 정할 것이 없다.

### `CLAUDE.md` 의 "1순위 결함" 서술이 낡았다

`CLAUDE.md` 가 **"대화가 위키에 아무것도 안 쓴다 … 이게 이 제품의 1순위 결함이다"**
라고 적고 있었는데, **그 문장이 쓰인 바로 그날(2026-08-17) #1224 가 그걸 고쳤다.**
`src/lib/chat/keep-exchange.ts` 의 헤더가 스스로 "대화를 위키로 보내는 길
(Simon 1순위 결함, 2026-08-17)" 이라고 적고 있다. #1236(08-18)은 그 위에 자동
저장 게이트를 얹은 것이다.

⚠ 이 문서 초판이 **#1236 만 지목했는데 부정확했다.** 배선은 #1224 다.

이 파일은 모든 새 세션이 가장 먼저 읽는다. 고치지 않으면 **세션마다 이미 해결된
결함을 1순위로 잡고 시작한다.** 정정하고 원문은 취소선으로 보존했다.

`conversation.ts` 쪽 서술은 아직 맞다 — 엔진은 여전히 읽기만 하고 쓰기는 화면이 한다.
그게 맞는 분리다(엔진은 LLM 호출, 동의 판단은 화면).
