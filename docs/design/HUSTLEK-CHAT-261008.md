# 허슬케이 초상화와 대화 화면 개선

Simon 지시 2026-10-08: 초상화를 고정하고 영역을 채우며, 대화 내용에 맞게 표정을 바꾼다. 입력은 자동 줄바꿈하고, 각 메시지에 아바타를 표시하며, 제안은 입력창 바로 위 한 행에 둔다.

## 구현·완료 기준

- 원본 PNG는 유지하고 투명 여백을 제외한 얼굴 구도를 공통 적용한다. 상하 움직임, 포인터 추적, 무작위 유휴 표정은 제거한다.
- 사용자 메시지는 저장한 프로필 아바타, 답변은 내용에 맞는 허슬케이 표정으로 표시한다. 로컬 표시 정책만 사용하며 추가 모델 호출이나 데이터 수집은 없다.
- 입력은 1~5행으로 늘고 이후 내부 스크롤한다. 웹 Enter 전송, Shift+Enter 줄바꿈, 한글 조합 중 Enter 비전송을 검증한다.
- 제안 행은 입력창과 함께 고정하며 대화 스크롤 공간을 차지하지 않는다. 답변별 중복 담기 버튼은 제거한다.
- 실질적인 대화가 쌓이면 위키 담기를 첫 번째에 강조한다. 기존 직전 질문·답변 원문 한 쌍 저장 계약과 자동 저장 동의를 유지한다. 실패는 입력창 옆에 남기며 재시도할 수 있다.
- 회귀 검사, 전체 verify, Android 번들, PR CI, 8081 실제 화면과 app:parity로 확인한다. 실제 기기 검증 여부는 결과에서 별도로 밝힌다.

최종 실행 근거는 Git 공통 상태 `HUSTLEK-CHAT-261008.json`과 HTML 완료 보고서에 기록한다.
