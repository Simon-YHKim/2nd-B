# Android 사진·녹음 공유 받기

근거: Q-261014-29(DECISIONS.md 2026-10-14 16:47). 기존 글 공유에 녹음 파일과 사진을
추가한다. 녹음은 기존 통화 회고의 성인·한국 범위로 제한한다. Q-261015-83에 따라
지문 잠금·오류 수집·인터넷 표시와 새 APK 한 번에 묶어 폰에서 확인한다.

## 사용자 흐름

- 사진 한 장: Android 공유 → 기존 사진 입력 화면 → **공유한 사진으로 사진과 본문 바꾸기**
  → 로컬 미리 보기 → 기존 **글자 추출** → 기존 검토·수정 및 저장 승인.
  공유 도착만으로 원래 본문을 덮어쓰거나 OCR·저장을 시작하지 않는다.
- 녹음 한 개: Android 공유 → 기존 통화 회고 → 기존 안내 확인 → **공유한 녹음을 글로 옮기기**
  → 인증된 기존 음성 경로·안전 판정 → 텍스트 검토 → 별도 저장 승인.
  공유 도착만으로 복사·음성 전송·저장을 시작하지 않는다. 파일 선택 경로에도 같은 범위를 적용한다.
- 로그인·프로필·비밀번호 복구·첫 설정이 앞을 막으면 기존 공유 거절 안내를 사용한다.
  로그인 뒤 자동 재개하는 큐는 없다. 여러 파일은 일부만 골라 처리하지 않고 안내로 거절한다.
- iOS 공유 확장과 웹 PWA 파일 공유는 이번 Android 범위에 들어가지 않는다.

## 충돌 확인과 범위

기존 통화 회고가 ‘한국’이라고 설명하면서 실제로는 한국어 UI만 확인하던 오류가 있었다.
이번 변경은 기존 법역 resolver `resolveJurisdiction().country === "KR"`를 추가한다.
이 resolver는 기기가 제공하는 지역 코드/기존 QA 운영 설정을 소비한다. 한국어를 국가로
추정하거나 GPS·IP를 새로 수집하지 않으며, 거주지를 인증했다는 뜻도 아니다.
국가 미확정·한국 외·연령 미확정·미성년은 파일 읽기와 음성 전송 모두 막는다.

기존 한국어 UI 제한도 유지한다. 한국에서 영어 UI를 여는 확대는 기존 음성 위기 안내의
언어→번호 선택을 국가 기준으로 분리한 뒤 별도 검토해야 한다. 이번에 영어를 열면
한국 계정에서 988로 흐를 수 있어 열지 않았다. 회귀 테스트가 **한국어 ≠ 국가**를 고정한다.
단말에 전달된 미확정 공유 핸들이 잠깐 존재하는 것과 통화 회고 전송 허용을 구분한다.

## 파일·소유 경계

`withAndroidShareTarget`가 SEND/미디어 필터, MainActivity 배선, Kotlin 브리지 및
MainApplication 등록을 함께 만든다. 새 npm 의존성·광범위한 사진/저장소 권한은 없다.
기존 텍스트 및 인증 링크 동작은 유지한다.

| 경계 | 동작 |
|---|---|
| 수신 | 실제 SEND의 content URI 한 개·읽기 grant 필요. file/http URI·자기 앱 provider·복수 파일 거절 |
| 주소 위조 | 라우터에는 UUID 핸들만 전달. 네이티브 메모리에 실제 SEND가 만든 미수신 항목이 있어야 복사 가능 |
| 대기 | 미수신 항목은 최신 한 개, 5분 후 폐기. 복사 중/미리 보기 포함 최대 네 개. 앱 복원·히스토리 재전달 거절 |
| 읽기 | 앱 비공개 캐시에 16 KiB씩 복사. 실제 누적 바이트로 제한. 워커 두 개·대기 큐 없음·15초 제한 |
| 녹음 | 최대 3,000,000바이트. 헤더·신고 MIME·MediaExtractor 음성 트랙 대조. 영상 트랙 거절 |
| 사진 | 최대 12,000,000바이트·24MP. JPEG/PNG/WebP/HEIC/HEIF 실제 디코더·MIME 대조. 방향 반영 후 최대 변 1600 이하로 JPEG 재인코딩(최대 2,000,000바이트), EXIF/GPS 메타데이터 미전달 |
| 처리 | 기존 인증된 OCR·음성 경로, 위기 안내, 명시적 검토·저장 조건 유지 |
| 소거 | 취소·실패·부분 복사·소유 계정 변경 시 생성 캐시 폐기. 복사 중 화면 이탈은 취소, 성공한 미리 보기는 교체·화면 언마운트 때 해제. 원본 provider 파일 삭제 안 함 |
| 프로세스 종료 | 메모리 핸들은 사라짐. 남은 자체 캐시는 다음 브리지 초기화/복사 때 정리 |

`shared-media-native`의 계정 구독은 root에서 로드한다. 공유 화면이 로그인 경계로 열리지
않은 동안에도 A→B, A→로그아웃의 네이티브 폐기를 요청한다. 복사/전송의 JS 결과는 기존
계정 epoch와 AbortSignal로 즉시 무효화한다. 첫 `null→복원된 A`는 콜드 스타트 공유를 보존한다.
같은 화면으로 다른 녹음이 도착하면 공유 요청 세대를 바꾸고 이전 전사를 취소한다.
이전 검토 본문은 지우고 새 파일의 명시적 전송 버튼을 보여 준다. 성공 후 URL 값을 지우는
ACK는 새 공유로 세지 않으므로 검토 화면을 유지한다. 이미 승인한 이전 저장은 완료될 수
있지만 늦은 결과가 새 공유 화면을 이동시키거나 바꾸지는 않는다.

음성·OCR은 취소 전에 확인한 위기 판정을 감사 기록 대기보다 먼저 계정 소유 앱 안내로
전달한다. 어휘 RED, 의미 RED, OCR proxy 위기 거절이 해당한다. 같은 계정에서 새 공유나
사진 교체·화면 이탈이 생겨도 이미 표시한 안내를 지우지 않는다. 요청별 1회 표시는 조기
알림·최종 음성 결과·OCR 오류 처리가 공유하므로 닫은 안내를 늦은 결과가 다시 열지 않는다.
계정 변경(A→로그아웃→A 포함)은 안내를 지운다. 취소 뒤 도착한 미분류 응답은 기존 fence로
거절하며 되살리지 않는다. 동의 거절·계정 세션·전송 취소 검사는 그대로 유지한다.
옵션을 쓰지 않는 다른 모델 호출의 반환·감사 동작은 바뀌지 않는다.
취소를 무시하는 provider가 열기/읽기에서 멈추면 15초 뒤 UI에 실패가 돌아오고 두 워커
이상의 작업은 시작하지 않는다. OS가 provider를 정리하기 전까지 워커가 남을 수 있다.

## 검증과 남은 확인

재사용 가능한 Jest 테스트는 실제 라우팅 함수·소유 lease·화면 핸들러를 실행한다.
계정 교체/취소/늦은 복사, 위조 주소·MIME·크기, 국가/연령, 두 번 누르기, 위기 응답,
미리 보기와 OCR/저장 분리를 검증한다. 기존 텍스트 공유·draft·안전 테스트도 함께 실행한다.
`shared-audio-redelivery.test.ts`와 `shared-photo-crisis-boundary.test.ts`는 실제 boundary·안전
판정기·인증 계정 lease를 연결하고 외부 proxy/model/audit I/O만 대역으로 둔다. 감사 대기,
의미 판정 대기, OCR 422, 동의 거절, 이미 닫은 안내, 계정 ABA, 미분류 취소를 재현한다.

```sh
npx jest --runInBand src/app/__tests__/shared-audio-redelivery.test.ts src/app/__tests__/shared-photo-crisis-boundary.test.ts
```
Kotlin은 Android API 35 android.jar 및 실제 React Native 0.85.3 AAR의 classes.jar로
별도 컴파일한다. Android SDK 전체 빌드와 폰의 실제 provider 동작을 대체하지 않는다.

재현 명령(저장소 루트, JDK 17 이상의 `java` 및 `jdk.jartool` 모듈 필요):

```sh
node scripts/check-android-share-media-native.cjs \
  --kotlin-home=/path/to/kotlinc \
  --android-jar=/path/to/android.jar \
  --react-aar=/path/to/react-android-0.85.3-debug.aar
```

도구는 실제 prebuild 함수로 두 Kotlin 파일을 생성하고 AAR의 실제 `classes.jar`와 컴파일한다.
입력 해시를 출력하고 임시 바이너리를 지운다. 다운로드·패키지 설치·네트워크 호출은 하지 않는다.
이어서 실제 `take` 함수 본문을 제어된 JVM 스케줄러와 실행하여 성공 직후 timeout,
timeout 뒤 늦은 복사, active 확인과 CAS 사이 timeout의 세 가지 경합도 검증한다.
실제 Android 파일 제공자/디코더를 실행하는 테스트는 아니다.
2026-10-15에 사용한 입력은 아래 공개 배포본이며, 저장소에는 바이너리를 넣지 않는다.
앱의 RN 버전이 바뀌면 `package.json`과 같은 버전 AAR로 다시 확인한다.

- Kotlin 2.1.20: <https://github.com/JetBrains/kotlin/releases/download/v2.1.20/kotlin-compiler-2.1.20.zip>
- Android API 35: <https://raw.githubusercontent.com/Sable/android-platforms/master/android-35/android.jar>
  (정식 Android SDK가 있으면 해당 플랫폼의 android.jar 사용)
- RN 0.85.3: <https://repo.maven.apache.org/maven2/com/facebook/react/react-android/0.85.3/react-android-0.85.3-debug.aar>

APK 통합 후 확인할 일:

1. 갤러리 JPEG/HEIC와 녹음 앱 M4A를 콜드/웜 스타트에서 공유. 기존 글·인증 링크 회귀 확인.
2. 사진 회전·미리 보기·추출·승인·원본 보존, 녹음 검토·승인·원본 보존 확인.
3. 두 파일, 3MB 초과 녹음, 12MB/24MP 초과 사진, 영상 MIME 위장, grant 상실 안내 확인.
4. 취소·뒤로 가기·다른 모드/새 글 작성·앱 종료·A→B·로그아웃에서 늦은 결과/잔여 캐시 확인.
5. 연령/국가 미확정·미성년·한국 외·영어 UI 차단, 한국어 UI지만 국가가 한국 외인 경우 차단.
6. 잠금·오프라인·오류 수집과 함께 설치한 APK에서 경로·동의·안전 번호를 확인.

폰/에뮬레이터가 없는 이 환경의 코드 검사만으로 위 폰 확인을 완료했다고 보고하지 않는다.
