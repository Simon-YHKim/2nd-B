실제 화면 캡처가 아닌 코드·번역 값의 정적 전후표입니다.

주요 변화

변경 전

설정: 기록 → /records

저장 뒤: 기록 보관소 보기

기록 목록 수: 별가루

저장한 글: 별가루를 저장했습니다

변경 후

설정의 중복 기록 줄 제거

저장 뒤: 위키 보기 → 기존 /records

기록 목록 수: 기록

저장한 글: 기록을 저장했습니다
