# 별자리 홈 확대 막대와 주머니 폰 간격

근거: `DECISIONS.md:196-197`, Simon 2026-10-10 19:00의 다음 UI 개선 결정
(Q-261010-21~23 중 homezoom 갈래). 별도 감사 G 번호는 발주서에 없습니다.

## 확인한 의도와 결함

- `PocketPhone.tsx`는 104×192 프레임 중 위쪽 44px만 보여 주고, 올릴 때
  148px 이동합니다. 폰 아래를 자르는 연출은 그대로 유지합니다.
- 기존 390×844 및 360×780에서 `getBoundingClientRect()` 기준 막대와 폰의 전체
  터치 프레임이 7,072px² 겹쳤습니다. 확대 버튼 1,936px², 눈금 조작부 2,704px²가
  그 안에 놓였습니다.
- 실제 보이는 폰 및 부모의 `overflow: hidden`을 적용한 웹 터치 영역과의 겹침은
  수정 전에도 0px²였습니다. 웹에서 폰이 확대 버튼을 가로챘다는 증거는 없습니다.
  이번 수정은 폰 연출을 유지하면서 전체 프레임도 서로 떨어뜨리는 배치 변경입니다.
- `docs/design/`, `docs/deep-space-nav-contract.md`, 캐논 JSON 및 캐논 테스트에서
  막대와 폰의 이 겹침을 요구하는 결정이나 좌표는 찾지 못했습니다. 기존 소스 계약은
  폰의 44px 노출, 한 줄 막대, 별 카메라 동작을 고정하며 그대로 통과합니다.

## 바뀐 배치

쉬는 홈과 수동 확대 상태에서 막대 전체를 위로 옮깁니다. 이동량은 실제 막대 행 높이
+ 폰 노출 높이 + 기존 `m3.spacing.s4`입니다. 측정된 행 높이는 72px이고 이동량은
124px입니다. 위쪽 음수 margin과 아래쪽 같은 크기의 양수 margin을 함께 적용해
별자리 영역의 높이와 폰 좌표를 유지합니다. absolute 덮개나 z-index 변경은 없습니다.

오른쪽에 폰 너비를 비우는 방법은 360px에서 눈금 폭이 170px에서 58px로 줄어듭니다.
숫자를 덜어내거나 조작부를 줄이지 않기 위해 막대 전체를 옮겼습니다.

폰을 올린 상태, 별에 초점이 간 상태, 대화창이 열린 상태는 기존 배치를 유지합니다.
오프닝, 카메라 제어, `PocketPhone.tsx`, 별과 링크, 캐논 값은 변경하지 않습니다.
