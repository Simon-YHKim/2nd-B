# 화면 전환 모션 · 2026-10-08

Simon 요청: 나의 핸드폰 안은 iPhone처럼, 밖은 2D 픽셀 모션으로 모든 화면 전환을 일관되게 만든다.

## 구현 범위와 완료 기준

- 공유 전환 규칙: 폰은 튀지 않는 감속, 바깥은 정수 좌표의 계단식 이동. 픽셀 그림의 정지 상태 격자는 유지한다.
- 폰 앱 열기·앞/뒤 이동·홈·페이지·알림, 전역 라우트와 설문/탭/단계 본문, 모달·시트의 진입/닫기에 공통 규칙을 적용한다.
- 화면 이동은 즉시 반영한다. 전환 때문에 이전 화면을 복제하거나 데이터 작업을 지연시키지 않는다. 공지/설문 안내처럼 닫으며 이동하는 모달은 짧은 닫힘이 끝난 뒤 이동하며, 포커스를 잃으면 예약을 취소한다.
- OS 움직임 줄이기와 앱 라이트 모드에서는 즉시 표시한다. 도중 설정 변경·빠른 재이동·포커스 상실·언마운트는 진행 중 모션을 취소한다.
- 안드로이드 모달 포커스 가드, 하드웨어 뒤로가기, 계정 경계, 폰 스크롤/제스처 소유권을 유지한다.

완료: 정책/생명주기 회귀 검사, 전체 `npm run verify`, 브라우저에서 폰/바깥/시트 및 축소 모션 확인, PR CI와 머지, 실제 8081 확인, `npm run app:parity` 같음.

## 분담

- root: 공유 모션 정책·본문 전환 primitive·OS 축소 모션·통합 검증.
- phone_surface_audit: DashboardPhone 내비게이션 및 정책 회귀.
- phone_ops_ui: 전역 라우트와 공통 단계/탭 본문.
- phone_shared_ui: 네이티브 모달을 유지하는 공유 모달 모션과 포커스 가드.

초기 체크포인트: origin/main `62ec44e8`, 별도 `feat/transition-motion-261008` 워크트리. 공용 main의 기존 변경은 수정하지 않는다.

- 릴리스 설정의 별도 8084 브라우저(390×844 / 1280×960): 앱 열기·앞/뒤·홈·페이지, 폰/바깥 날짜 모달의 열림/닫힘, 바깥 설정 이동 확인.
- 프레임 측정: 폰은 연속 감속(관측 구간마다 18–22개 좌표), 바깥은 정수 좌표 6단계와 최종 정착. 종료 후 모달 내용 제거.

- 검토 중 발견한 투명 overlay 복귀 깜박임은 실제 Expo 56의 closest Stack 구독으로 해결. 내부 `__root` 계층을 포함한 설치본 테스트를 추가했다.

이 기록의 8084는 브랜치 검증이다. PR·CI·머지 이후 8081 확인과 앱 코드 일치는 최종 완료 보고서 및 공유 세션 상태에 별도로 기록한다.
