# 허슬케이 말하기·대기 표정과 메시지 이름

Simon 지시 2026-10-08: 별자리 대화 글이 표시될 때 입이 움직이고, 평소에는 게임 캐릭터처럼 가끔 웃음·하품·졸음이 나타난다. 메시지는 초상화 오른쪽에 닉네임, 그 아래에 채팅을 둔다.

## 구현과 완료 기준

- 기존 고정 프레임과 PNG 원본을 유지한다. 말하기는 실제 typewriter 진행과 연결하며 얼굴 전체 대신 입 주변만 바꾼다. 문장부호·완료·바로 읽기에서는 입을 닫는다.
- 별자리의 현재 초상화만 대기 표정을 허용한다. 짧은 미소 사이에 충분한 정지 시간을 두며, 하품·졸음은 오래 조용할 때만 허용한다. 앱 반응·생각 중·명시한 맥락 표정이 우선한다.
- 화면 이탈·덮는 알림·폰 열기·백그라운드·숨긴 웹 탭에서는 멈춘다. 움직임 줄이기를 따르고 타이머·구독을 해제한다. 본문은 잠시 가려졌다가 돌아오면 읽던 위치부터 이어진다.
- 과거 채팅의 아바타는 메시지 맥락 표정을 유지한다. 사용자 프로필 닉네임은 현재 계정 소유 확인을 거치며, 없으면 기존 다국어 '나'를 표시한다. 메시지 그룹의 좌우 정렬과 입력창 위 추천 행은 유지한다.
- 새 네트워크 요청·모델 호출·개인정보 저장·의존성을 추가하지 않는다.
- 런타임 회귀 검사, 전체 verify, Android 번들, 실제 브라우저, PR CI, 8081 반영 및 app:parity까지 확인한다. 실제 기기 테스트 여부는 별도로 기록한다.

앞선 [고정 초상화 설계](HUSTLEK-CHAT-261008.md)의 무작위 유휴 표정 제거는 이번 요청에 따라 별자리의 명시적 대기 모드에 한해 확장한다. 위치 이동·포인터 추적은 계속 사용하지 않는다.
