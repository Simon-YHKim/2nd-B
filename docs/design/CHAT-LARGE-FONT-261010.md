## 변경과 경계

- `CHATFONT-01`: Android에서 실제 입력 높이가 한 줄 상자 이내이면 입력 알약과
  보내기 버튼 행을 가운데 정렬합니다. 자동 줄바꿈·명시적 줄바꿈으로 높이가 커지면
  기존 아래 정렬을 사용합니다. 입력을 비우면 이전 여러 줄 높이를 기다리지 않고
  가운데 정렬로 돌아갑니다. 실제 높이는 기존 `ChatTextInput.onLayout` 전달을 통해
  입력 컴포저 안에서만 갱신하며 대화 본문 상태에 올리지 않습니다.
- 한 줄 판정은 줄 높이 22, 위아래 여백 7, 휴대폰 테두리 2를 기준으로 합니다.
  휴대폰 안의 최소 높이 44도 포함합니다. 글자 크기에는 배율을 다시 곱하지 않습니다.
- `CHATFONT-02`: 상태 설명은 1.3배까지 한 줄, 그 위에서는 최대 두 줄입니다.
  두 줄을 강제로 채우지 않으며, 사용 횟수와 지우기는 기존 오른쪽 행에 남습니다.
  `maxFontSizeMultiplier={0}`은 React Native의 무제한 값으로,
  공용 `Text`가 기본 적용하던 1.7배 상한을 이 설명에서 해제합니다.
- #2212의 최소 높이 계산은 공용 순수 함수로 이동했으며 결과는 그대로입니다.
  Android 1.0·1.3배는 36, 1.31배는 47, 2.0배는 62, 최대 높이는 124입니다.
  휴대폰 컴포넌트의 기존 44 최소 높이도 유지합니다.
- 웹은 배율 1, 기존 아래 정렬과 한 줄 상태 설명을 유지합니다. iOS 입력 정렬도
  기존대로입니다. 문구·색·탭·말풍선·대화 엔진·저장 동작·의존성은 변경하지 않습니다.
