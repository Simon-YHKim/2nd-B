# 허슬케이 캐릭터 교체와 담기 형식 선택

Simon의 2026-10-08 지시: 일반/4W1H 두 이름을 항상 표시하고, 제공한 얼굴 표정 에셋으로 세컨비를 허슬케이(HustleK)로 교체한다.

- 담기의 공용 `SegBtn`은 일반을 기본으로 선택한다. 같은 항목 재선택은 무동작이며, 각 형식의 초안·첨부·OCR·저장 경로를 유지한다. 선택 상태와 도움말을 접근성 속성으로 제공한다.
- `assets/hustlek`에 제공 PNG 48종을 바이트 그대로 보관한다. 정적 registry → `HustleKPortrait` → 기존 `SecondbHead` 진입점으로 연결한다. 공유 카드와 공개 prototype의 별도 얼굴도 같은 원본을 사용한다.
- 기존 13개 동작 상태는 공급된 표정으로 대응한다. 반응 > 대기 중 홀드 > 유휴 > 기본 기분 순서, 타이머 정리, 동작 줄이기 설정, 큰 초상화의 평행 이동을 유지한다. 로봇 눈·입 오버레이와 persona 색상 보정은 제거한다.
- 5개 언어 표시 이름, 안내·접근성·대화/생성 소개와 공개 설명은 허슬케이/HustleK로 바꾼다. 앱 이름 PolaScope, `/secondb`, 저장 키, 서버 purpose `secondb_chat`과 기존 데이터는 호환을 유지한다.
- 오프닝의 기존 승인 허슬케이 전신 동작, 북극성·폰·별자리 에셋은 각자의 의미를 유지한다.
