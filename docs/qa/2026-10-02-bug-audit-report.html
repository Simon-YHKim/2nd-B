HIGH 2. Android 하드웨어 백버튼 무한 루프 트랩 (BackHandler Loop)
src/components/dashboard/DashboardPhone.tsx:118-130
증상 및 UX 영향

안드로이드 실기기에서 핸드폰(DashboardPhone) 모달 루트 상태일 때 하드웨어 백버튼을 누르면 종료 확인 모달이 열렸다 닫혔다를 무한 반복하며, 백버튼으로 핸드폰 화면을 절대 닫을 수 없습니다.

근본 원인 (Root Cause)
// DashboardPhone.tsx
const backInside = useCallback(() => {
  scrollY.current = 0;
  if (exitPrompt) { setExitPrompt(false); return; } // ① 확인창 열린 상태에서 백버튼 누르면 창만 닫음
  ...
  if (tab === "tools") { setTab("dashboard"); return; }
  setExitPrompt(true); // ② 루트에서 백버튼 누르면 확인창을 엶
}, [exitPrompt, ...]);

useEffect(() => {
  const listener = BackHandler.addEventListener("hardwareBackPress", () => {
    backInside();
    return true; // ③ 항상 true를 반환하여 Android 시스템 기본 뒤로가기(닫기)를 차단함
  });
  return () => listener.remove();
}, [backInside]);

루트에서 백버튼 클릭 → exitPrompt(true) → 다시 백버튼 클릭 → exitPrompt(false) → 다시 클릭 → exitPrompt(true)로 무한 루프를 돕니다. closePhone()이 절대 호출되지 않습니다.

해결 방안

exitPrompt가 이미 활성화된 상태에서 한 번 더 하드웨어 백버튼을 누르면 closePhone()을 호출하여 닫히도록 수정해야 합니다.

MEDIUM 4. 잘못된 레코드 라우트 시 Uncaught `URIError` 크래시
src/components/dashboard/DashboardPhone.tsx:303
증상 및 위험도

잘못 인코딩된 URL(예: 단독 % 또는 비표준 인코딩)을 통해 /record/... 라우트에 진입할 경우 React 전체 컴포넌트 트리가 Uncaught URIError로 화이트아웃/크래시됩니다.

근본 원인 (Root Cause)
const selected = route.startsWith("/record/") 
  ? [...records, ...interviews].find((record) => record.id === decodeURIComponent(route.slice(8))) 
  : null;

decodeURIComponent()가 try...catch 방어 코드 없이 컴포넌트 렌더링 본문에서 직접 호출됩니다.

해결 방안

안전한 헬퍼 함수 safeDecodeURIComponent(str)를 사용하여 예외 발생 시 원본 문자열을 폴백으로 반환하도록 방어합니다.
