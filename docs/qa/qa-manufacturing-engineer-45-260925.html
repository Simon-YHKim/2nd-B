북극성 페르소나 생성: 연결 확인, 실제 제안 실패

북극성은 ‘참고한 별가루 8개’를 표시해 스크랩 2건과 인터뷰 6건의 연결을 확인했다. mock 서버에서 ‘기록으로 페르소나 제안 받기’를 누르자 감사 원장에 persona_narrative 1회·persona_synthesis 2회가 모두 mock:gemini-2.5-flash로 기록됐고, 버전 1 페르소나의 요약 캐시는 생성됐으나 역할 카드(role_cards_v1)는 없었다. 모의 응답을 빈 제안으로 돌리는 현재 코드와 일치한다. 별도 8082 개발 서버를 live로 열어 시도했을 때 처음에는 Edge 프록시 플래그가 빠져 안전 경계가 호출을 막았다. EXPO_PUBLIC_LLM_VIA_EDGE_FUNCTION=true를 추가하고 웹 번들에 live/true가 들어간 것을 확인한 뒤 재시도했지만 화면은 ‘페르소나를 불러오지 못했어요’라고 표시했다. 재조회한 감사 원장에 새 live 행이 없어 유료 호출 성공·카드 생성·승인은 확인되지 않았다. 두 번째 실패의 정확한 예외는 화면이 숨기므로 콘솔/프록시 응답을 별도로 추적해야 한다. 시험용 8082 서버는 중지했고 기존 8081 서버는 그대로 유지했다.

새로 재현된 코치마크 문제

온보딩에서 첫 스크랩을 저장한 후 홈에 1/4 코치마크가 나타났다. 강조된 세컨비 머리를 눌러 2/4로 이동하고 메모 선택→문장 입력→저장까지 했지만 캡처 화면은 3/4에 머물렀다. 기록 목록은 2건으로 늘었는데 홈으로 돌아오면 다시 1/4였다. 다른 로컬 원점 localhost:8082에서는 기록 9건이 있는데도 다시 1/4가 나타났다. 진행을 위해 각 원점에서 QA용 ‘다시 보지 않기’를 눌렀다. 코치마크 완료 상태가 실제 첫 기록과 연결되지 않는 회귀로 추적해야 한다.

메타비 대화 1건: 모의 응답과 실제 호출

같은 질문을 메타비에서 한 번은 기본 mock 모드로, 한 번은 프로세스 한정 live 모드로 보냈다. 모의 응답은 고정된 ‘오프라인 미리보기’ 문구였고 감사 로그에 mock:gemini-2.5-flash로 남았다. 실제 호출은 openai-proxy HTTP 200으로 완료됐으며 감사 로그의 purpose=secondb_chat, model_used=gpt-5.6-terra, total_tokens=1000, latency_ms=3867을 확인했다. 추가 과금 방지를 위해 로컬 서버는 다시 mock으로 실행 중이다.

실제 답변은 직업을 확인할 자료가 없다고 말했다.
