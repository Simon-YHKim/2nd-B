대시보드 → 데이터 → Garmin Connect에서 기존 /import 화면으로 이동합니다. iOS는 Apple 건강, Android는 Android 14 이상 Health Connect 공유를 먼저 설정해야 합니다. 기존 앱은 지원되는 걸음·운동·수면·심박 자료를 읽습니다. 실제 전달 항목과 상세도는 Garmin 공유 기능과 OS 권한에 따라 다릅니다.

다른 기기의 건강 자료가 있어도 Garmin 연결 완료로 표시하지 않습니다. 현재 저장된 자료의 출처는 HealthKit 또는 Health Connect이며 원래 Garmin 기기인지 증명하지 못합니다. 웹 브라우저에서는 OS 건강 자료를 가져올 수 없습니다.

검증 결과
  • 대시보드 단위 테스트: 2개 스위트, 14개 통과. Garmin 미성년·연령 미확인 제한과 허위 연결 표시 방지 포함.
  • TypeScript, 변경 파일 ESLint, 5개 언어 키 패리티, 번역 누락, 금지 어휘 검사 통과.
  • Orca에서 localhost:8081/dashboard 이동은 성공했으나 화면 스냅샷 중 런타임 연결이 종료되어 육안 검증은 완료하지 못했습니다.
  • Garmin 기기 → OS → 설치 앱 전체 흐름과 실제 데이터 수집은 검증하지 않았습니다.
직접 연동을 위한 다음 단계와 공식 근거

Garmin 개발자 프로그램 신청·승인 후 Health / Activity API용 OAuth 동의, 서버 커넥터, 출처 식별, 중복 방지와 연결 해제를 구현해야 합니다. 이번 변경에서는 외부 등록·새 자격증명·유료 호출·운영 마이그레이션을 수행하지 않았습니다. 일부 지표의 상업적 조건은 별도 확인해야 합니다.
