2026-09-24 17:17:34 KST · 로컬호스트 화면 검증

2개 입력 트랙프로필에서 생애 기록과 직장·현재 기록으로 갈라집니다.
첫 기록으로 다음 별 열림이전 별의 첫 저장 입력이 L2가 되면 다음 별에 입력할 수 있습니다.
포커스와 복귀별 터치 시 별자리와 선택 별을 부드럽게 확대하고, 빈 하늘 터치 시 축소합니다.

입력 순서

입력 잠금은 홈의 ‘여행하기’, 별 요약의 인터뷰 버튼, 직접 연 인터뷰 주소에 공통 적용했습니다. 기존 기록은 잠긴 별의 요약에서도 계속 읽을 수 있습니다. 나이가 닿지 않은 시기를 잠그는 기존 규칙도 유지합니다.

로컬호스트에서 확인한 화면

별자리 홈에서 별을 선택하면 기록 주제와 선행 별 안내가 나타났습니다. 빈 하늘을 누르면 소개 상태로 돌아왔고, 잠긴 ‘지금’ 별의 여행 버튼은 비활성화됐습니다. 별 요약은 기존 기록 1건과 진행도를 보여주면서 추가 입력 버튼을 감췄습니다. 직접 인터뷰 주소도 ‘직장’ 선행 입력 안내를 표시했습니다.

검증과 남은 범위

타입 검사, 5개 언어 키 일치, 린트(기존 경고만), 단일 프로세스 Jest 779개 스위트·9,928개 테스트가 통과했습니다. npm run verify의 정적 게이트와 UI 검사는 통과했으나, 병렬 Jest에서 다른 검사가 생성·삭제하는 임시 파일을 읽는 경합으로 1개 스위트가 실패했습니다. 모바일 네이티브 기기에서의 손동작·화면 잘림은 아직 직접 확인하지 못했습니다.
