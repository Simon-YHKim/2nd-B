사진 선택과 권한 거부 경로 확인

Pixel 7 Android 16 x86_64 에뮬레이터에서 기존 x86_64 APK의 네이티브 화면을 조작했다. 최신 main 앱의 회귀 검증은 아니다.

3개 경로선택기 · 권한 거부 · 글꼴 확대
3개 화면저장소에 증거 보존
0건사진 선택·메모 저장
재현과 결과
  • Scrap → Photo → Library: Android Photo Picker가 열렸다. 취소 후 앱으로 복귀했다.
  • Camera 권한 거부: 안내와 Dismiss/Try again이 나타났고 뒤로가기로 사진 화면에 복귀했다.
  • 글꼴 130%: Camera·Library·Save piece·하단 탐색이 보였다. 검사 후 100%로 복원했다.
빌드와 적용 범위

실행한 x86_64 APK는 4ee03669의 이전 수동 진단 빌드다. 최신 성공 APK 0e2bb32e는 arm64-v8a 전용이므로 이 에뮬레이터에서 네이티브 라이브러리 로드 오류가 났다. 이는 ABI 불일치이며 앱 결함으로 판정하지 않았다.

남은 검증과 증거

ARM 실기기의 최신 main에서 실제 사진 선택·OCR, 최대 글꼴, TalkBack, PolaScope 시스템 앱 이름을 확인해야 한다. 화면 증거와 상세 절차는 QA 기록에 있다.

운영 데이터·설정 변경 없음. 이 보고는 플랫폼 경로의 관찰 범위만 기술한다.
