촬영 때 처음 파일을 읽으면 420ms 화면 전환 전에 재생이 시작되지 못함별을 선택할 때 같은 셔터 player를 준비하고 촬영 시 재사용. 취소하면 대기 요청 폐기

설치된 SDK 함수를 실행하는 결정적 호스트로 실패를 먼저 재현했습니다. 실제 네이티브 드라이버와 기기 청취를 검증한 것은 아닙니다. 일반 브라우저의 첫 셔터 실패는 로그만으로 원인을 확정하지 않았으며, 별도로 파일 응답을 650ms 늦춘 재현을 통해 로딩 경합을 확인하고 보완했습니다. 파일이 더 오래 지연되거나 실패하면 소리를 건너뛰며 화면 이동은 기다리지 않습니다.
