첫 기록 코치마크

수정 전: 저장 직후 백그라운드 홈의 공지 모달이 완료 화면 위에 나타나 진행을 가렸습니다. 수정 후: 홈이 포커스된 동안에만 공지 모달을 열어, 기록 완료와 별자리 복귀를 막지 않습니다.

QA 계정에 테스트 메모 2건을 저장해 전후 흐름을 확인했습니다. 사용자 데이터 삭제는 하지 않았습니다.

발견과 처리

수정 완료 · 공지창이 코치마크를 가림

ConstellationHome이 다른 라우트 뒤에 남아 있어도 공지 Modal을 열던 문제입니다. 홈 라우트 포커스를 표시 조건으로 추가했습니다. 회귀 테스트는 수정 전 실패, 수정 후 통과했고 Orca에서 저장→복귀를 재검증했습니다.

수정 완료 · 사용 안내서 제목이 번역 키로 표시

/manual 상단에 manual.title이 노출됐습니다. 기본 번역 묶음이 manual인 화면에서 t("title")을 사용하도록 고쳤고, 한국어 제목이 브라우저에 표시되는지 확인했습니다.

수정 완료 · 읽은 공지가 새로고침마다 재표시

서버와 공유 저장소에는 읽음 기록이 있었지만 홈 화면의 React Compiler 캐시에는 빈 집합이 남았습니다. 읽음 상태 변경 번호를 snapshotReadIds(userId, readRevision)의 실제 입력으로 전달해 캐시를 무효화했습니다. 수정 전에는 같은 중요 공지가 새로고침마다 열렸고, 수정 후 두 차례 연속 새로고침에서 열리지 않았습니다.

주의 · 장시간 화면 순회 중 개발 서버 메모리 종료

반복적인 전체 페이지 이동을 약 48분 수행한 기존 Expo 서버가 Node 기본 힙 한도 약 4GB에 도달해 종료됐습니다. 힙 상한 6GB로 재시작했고 localhost:8081 응답과 영향을 받은 경로를 재확인했습니다. 메모리 증가의 근본 원인은 별도 조사 대상입니다.

추가 조사 · 기록 그래프 연결선 스위치 접근성

/records의 ‘태그 연결선 표시’는 클릭하면 베벨 색이 바뀌어 시각적 토글은 작동하지만, 웹 DOM의 role="switch" 요소에는 aria-checked가 없고 Orca 접근성 스냅샷은 계속 checked=false로 표시했습니다. 상태를 보조기기에 올바르게 전달하는지는 별도 수정·검증이 필요합니다.

범위 · 화면 진입과 기능 검증은 다릅니다

112개는 접근 가능한 화면·변형 경로의 진입 확인입니다. 상호작용은 코치마크 전 단계, 하단 탭, 기록 그래프 확대·목록, 홈 공지와 읽음 유지, 안내서 제목을 확인했습니다. 유료 AI 실행, 결제, 계정 변경, 데이터 삭제, 외부 전송, 파일·마이크 권한, 모든 화면의 모든 버튼은 실행하지 않았습니다. 개발 콘솔에는 React Native Web의 접근성 prop/이벤트 핸들러 경고가 남았습니다.
