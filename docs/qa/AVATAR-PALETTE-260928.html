아바타 팔레트: 그려서 내 기기에 보관

사용자 결정(2026-09-28)에 따라 공용 셰어 기능은 보류했다. 휴대전화의 아바타 팔레트에서 머리·옷·소품 픽셀 에셋을 직접 그리는 기능과 로컬 초안 보관만 준비한다. 첫 아바타 설정과 첫 번째 프로필 별의 아바타 편집은 그대로 이어진다.

이번 구현 범위

로그인한 사용자는 확대·이동·격자·기본 아바타 가이드·지우개·마지막 그리기 되돌리기·합성 미리보기를 이용해 그림을 만들고, 슬롯마다 초안 한 개를 저장하거나 삭제할 수 있다. 미리보기는 저장된 프로필 아바타에 그림을 적용하지 않는다.

공용 서버 업로드, 다른 사용자 갤러리, 다른 사람 그림 가져오기, 신고·차단, 에셋 판매는 현재 기능에 없다. 공유 재개 여부와 수익화는 이번 범위에서 결정하거나 구현하지 않는다.

사용 흐름

투명 64×64 레이어의 색 인덱스만 저장한다. 한 레이어는 불투명 칸 최대 1,024개이며, 제목은 선택 사항이다. 저장하지 않고 슬롯을 바꾸거나 화면을 닫으면 저장·버리기·취소를 고를 수 있다.

초안이 머무는 곳

환경저장 방식사용자가 알아둘 점
Android·iOS 앱계정 식별자 아래 슬롯별 초안. 기기의 암호화 저장소를 사용한다.다른 기기와 자동 동기화되지 않는다.
웹같은 브라우저의 localStorage에 계정별로 저장한다.웹 초안은 앱의 암호화 저장소와 다르며, 브라우저 데이터를 지우면 사라진다.
계정 삭제해당 계정의 로컬 초안을 삭제 절차에 포함한다.저장 실패나 읽기 오류가 나면 빈 그림으로 덮어쓰지 않고 재시도할 수 있다.
검증과 남은 확인
  • 통과: npm run verify 전체 게이트와 Jest 836개 모음·10,847개 테스트, npm run verify:web 정적 웹 문서 130개. 픽셀 규칙·디자인 참조·캐논 미러도 통과했다.
  • 서버 초안이나 운영 DB 적용은 이 로컬 팔레트 기능에 필요하지 않다. 첫 아바타 설정에 필요한 별도 users.avatar_spec 초안의 운영 적용 상태는 따로 확인해야 한다.
  • Android 실기기의 손가락 그리기·스크롤 충돌·성능은 아직 직접 확인하지 못했다.
