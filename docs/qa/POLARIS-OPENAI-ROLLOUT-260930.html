Polaris 원장과 OpenAI Edge 배포

2026-09-30 16:18 KST · 운영 프로젝트 zoacryukmdeivmolvyhj · 기준 main 354e8d03

승인된 0195·0198 마이그레이션과 openai-proxy 배포를 완료했다. Polaris 기능은 꺼져 있으며 동의 API 503 때문에 동의 전환과 유료 제공자 호출은 보류 중이다.

현재 운영 상태. 전역 llm_enabled=true, Polaris enabled=false. LLM_CONSENT_MODE의 실제 값은 확인되지 않았으며, QA 계정의 service-consent status는 배포 후에도 HTTP 503이다.

적용 순서

백업은 암호화 artifact 생성 성공까지 확인했다. 이번 작업에서 복호화나 재복원은 실행하지 않았다.
