검증 및 함께 수정한 문제
  • npm run verify 전체 통과: lint 오류 0(기존 경고 72), typecheck, 5개 언어, 안전 경계, 픽셀 규칙 146, 순환 참조 0, 라우트 등록, UI 검사, Jest.

  • 홈·대시보드 320/425/768px 화면 폭과 휴대전화 노출 확인. 별 확대 시 다른 별 버튼이 사라지는 것 확인.
  • 기록 그래프: 오른쪽 12회 이동으로 기존 그래프 범위 밖 진입, 원위치 복귀, 배율 변화, 캔버스 드래그 무반응 확인.
  • PixelPressable의 웹 aria-selected 전달을 수정해 대시보드 탭 선택 상태를 확인할 수 있게 했습니다.
  • 개발 Metro HMR의 eval을 막던 CSP는 개발 환경에서만 허용. 운영 CSP는 기존 strict 정책 유지.
  • expo-audio 웹 play Promise 유실로 생기던 이동 시 AbortError를 소유한 HTMLAudioElement Promise 처리로 수정. 전역 오류를 숨기지 않습니다.
  • QA tier service-only RPC 403은 본인 RLS 행의 실제 Brain·만료일 확인으로 수정. FORCE_TIER를 권한 근거로 쓰지 않습니다.
  • mock 인터뷰의 UNTRUSTED 닫는 태그 노출, 실제 질문의 사용자 1인칭 화자 혼동을 각각 parser·prompt 지침으로 보완했습니다.

아직 완료라고 말할 수 없는 부분

  1. 운영 배포 승인: DB 정산 초안 적용, 모든 관련 proxy 배포, canary 후 capability 활성화. 이 절차가 끝나야 일반 사용자 무료 2회가 실제 서비스에 적용됩니다.
  2. 외부 통합: 각 제공자의 지원 API·권한·앱 등록·사용자 동의 범위 확정. 사적인 대화 기록을 몰래 읽는 기능은 만들지 않았습니다.
  3. 원격 푸시 및 실기기: 토큰 등록·전송 서버·철회 및 계정 변경 처리는 추가 구현 대상. Android/iOS 빌드·실기기 알림/핀치가 아닌 다이얼 조작 검증은 미실시.
  4. 위키 데이터: 현재 QA 위키는 0페이지. 공용 제어와 코드 검증을 했지만 실제 위키 노드가 있는 화면의 E2E는 남았습니다.
