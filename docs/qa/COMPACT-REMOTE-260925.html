검증 방식과 남은 범위

localhost:8081을 실제 Edge 엔진으로 실행한 자동 UI 검사입니다. 마우스·터치 이벤트·키보드와 화면 경계를 검사합니다. 위키 데이터는 브라우저 내부 fixture이며 서버 기록을 추가하지 않았습니다.

첫 병렬 verify 실행은 임시 emdash 검사 파일이 생성·삭제되는 도중 다른 검사가 읽는 경합으로 2개 suite가 실패했습니다. 전체 게이트를 npm run verify -- --runInBand로 재실행해 통과했습니다. 제품 코드에 이 문제를 우회하는 변경은 넣지 않았습니다.

기존 Expo 의존성 정합성 경고는 남아 있습니다. 의존성 추가·업그레이드, 서버 변경, AI 호출, commit/push/배포는 하지 않았습니다. Android/iOS 실기기에서 최종 터치감 확인은 남아 있습니다.
