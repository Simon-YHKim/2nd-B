운영 보류 사유

  • 0179·0181·0189·0190·0192·0194·0195·0197·0198·0201은 현재 원장에 정확한 소스 이름이 없다. 이는 전체 누락 목록이 아니며, 별칭은 별도로 화해해야 한다.
  • 0177과 0196 효과는 날짜형 별칭으로 기록돼 있고 0172는 두 번 기록돼 있다. 다시 적용하거나 원장 행을 정리하지 않는다.
  • runtime_flags.llm_enabled=true를 읽었다. Edge secret·보상/Paddle 서버 플래그의 존재와 값은 이 도구로 확인할 수 없다. 보상 v91은 기존 버전이고, service-consent는 운영 함수 목록에 없다.
  • 실제 운영 데이터와 원장을 복제한 0191–0201 통합 리허설, Reward 서명·변조·재전송 canary, Paddle OFF·drain·sandbox는 미완료다. 최신 앱/웹 공개도 보류한다.
