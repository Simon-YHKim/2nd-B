무엇을 바꿨나요?

기존 2열 앱 목록을 4열 런처로 교체하고, 브랜드 헤더·밤마을 배너·대시보드/앱 탭·3페이지 표시·내부 5아이콘 독을 넣었습니다. 알림은 실제 미읽음 수를 표시하며, 기존 알림 상세·커뮤니티 연령 제한과 앱 경로를 유지했습니다. 작은 화면에서는 타일과 아이콘 크기가 디스플레이 높이에 맞춰 줄어듭니다.

카메라 조작 프롬프트는 어떻게 반영됐나요?

현행 망원경 조작 코드에 대칭 픽셀 조그 링, 고정 중앙 인덱스 아래 이동하는 줌 눈금 밴드, 단계식 양끝 페이드가 이미 구현돼 있었습니다. 관련 계약 테스트가 통과해 카메라 제어 로직을 중복 변경하지 않았습니다.
