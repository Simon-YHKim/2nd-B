  • 원점 터치의 즉시 상태 변경을 기존 카메라 반환 시간 640ms의 단계형 애니메이션으로 바꾸었습니다. 카메라의 화면 좌표를 원점까지 보간해 별자리와 눈금이 같은 경로를 따릅니다.
  • 별 선택 중에도 조작부를 숨기지 않고 비활성 상태로 표시합니다. 별 이동에 사용 중인 키프레임을 읽어 조그 방향과 다이얼 배율을 표시하며, 카메라와 반대 방향으로 움직이는 배경을 고려해 조그 방향을 보정했습니다.
  • 다른 별을 누르면 진행 중인 원점 복귀를 중지하고 현재 위치에서 새 이동을 시작합니다. 기존 모터·초점·셔터 소리는 유지하고 원점 복귀에는 모터 리듬을 연결했습니다.
