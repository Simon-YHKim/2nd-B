핸드폰 뒤 별자리 배경

QA 계정 화면 검증 · 2026-09-27 03:23:19 KST

홈에서 열기기존 별자리 화면을 유지한 채 핸드폰을 투명 모달로 표시
직접 진입/dashboard에서는 공용 별하늘을 배경으로 표시
닫기홈에서 연 경우 이전 별자리 상태로 복귀

검증

단위 테스트 3/3, TypeScript 타입 검사, 변경 파일 ESLint 통과. 브라우저에서 425×812와 768×900 화면을 확인했고, 홈 → 핸드폰 → 홈 복귀 및 직접 URL 진입을 확인했다.

구현 근거와 남은 주의 사항

홈의 별자리 장면을 복제하지 않고 실제 홈 화면을 모달 아래에 남겨 배경의 위치와 상태를 보존한다. 직접 진입에서는 밑에 홈 화면이 없으므로 기존 공용 별하늘을 사용한다.

개발 서버 콘솔에는 이 변경과 별개인 /2nd-B/manifest.webmanifest 404 및 React Native Web 경고가 남아 있다. Android 실기기 검증은 이번 작업에서 실행하지 않았다.
