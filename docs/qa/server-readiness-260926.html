검증한 범위

주석으로 SQL 전체를 숨기기, 잘못된 번호, 소유 표보다 이른 적용, 미선언 생성 블록의 우회를 재현한 뒤 차단했습니다. 독립 재검토도 통과했습니다.

실제 PostgreSQL에서 전제조건 실패·반복 적용·기존 66행 보존·70행 복구·사용자 데이터 불변·삭제 경합을 확인했습니다. 전체 70표의 실제 catalog와 Supabase CLI ledger 왕복은 실제 승격 후 실행해야 합니다.

정적 가상 승격은 OS 임시 폴더에서만 실행했습니다. 원본 파일 해시 불변과 임시 폴더 제거를 확인했습니다. 웹·Android 코드는 이번에 변경하지 않았고, 이전 커밋의 검증 결과는 이전 보고서에 있습니다.

현재 배포 상태와 다음 단계

운영의 공개 가입 계약 조회는 RPC가 준비되지 않아 게시 가드에서 실패했습니다. DB·Edge·secret·flag 변경, 결제, 모델 호출은 수행하지 않았습니다.

콘솔 소유자가 실제 스키마와 함수 서명을 읽고 번호를 예약한 뒤, 전체 승격 검증과 OFF/drain·canary를 거쳐야 합니다. 기존 승인 범위는 유지하며 새 패키지와 과거 21641bda 패키지를 혼합하지 않습니다.
