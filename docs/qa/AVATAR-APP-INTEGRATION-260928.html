사람 ↔ 동물동물도 일반 옷 6종을 선택한다. 직업 의상은 사람 모습에서만 보인다.
저장완성 이미지를 중복 저장하지 않고 사용자 소유의 작은 avatar_spec 레시피를 저장한다.

화면의 직업 의상 선택은 캐릭터 꾸미기 값이며 실제 프로필의 직업 텍스트를 바꾸지 않는다.

검증

  • 144개 PNG, 8픽셀 격자, 2,892개 조합, 앱·승인 렌더러 출력 일치 검사 통과.
  • TypeScript, 다국어, 픽셀 규칙, 웹 정적 내보내기와 전체 저장소 검증 실행.
  • 전체 검증 최종 결과: PASS · 828개 테스트 묶음 / 10,810개 테스트. 기존 lint 경고 71건은 오류가 아니다.
  • 새 SQL 회귀는 CI의 폐기형 PostgreSQL 단계에 등록했다. 로컬 SQL 실실행은 접속 자격증명이 없어 미실행.

공개 전 서버 순서

db/migration-drafts/UNNUMBERED_users_avatar_spec.sql은 아직 운영 DB에 적용되지 않은 초안이다. 콘솔 소유 세션이 다음 번호를 예약·적용하고, 인증 사용자 컬럼 권한과 본인/타인 RLS를 실제로 확인한 뒤 첫 웹 게시·OTA·새 네이티브 빌드를 진행한다.

이번 작업은 앱 코드와 로컬 빌드까지다. 연결된 Android 기기가 없어 실제 터치 반응성과 메모리는 기기에서 아직 확인하지 못했다.
