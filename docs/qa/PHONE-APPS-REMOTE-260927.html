화면 흐름

왜 이렇게 바꿨나
  • 상단 바는 알림 진입에 집중하고, 서비스성 기능인 AI 뮤지엄은 사용자가 기대하는 핸드폰 앱 목록에 배치했다. 커뮤니티의 상단 버튼은 제거했지만 기존 핸드폰 앱 진입은 유지했다.
  • 알림을 별도 전체 화면으로 전환하면 핸드폰을 조작한다는 흐름이 끊긴다. 그래서 목록과 상세를 핸드폰 프레임 내부에서 렌더링하고, 긴 목록은 FlatList로 처리했다.
  • 망원경 조작부는 PIXEL-CLAY의 정적 불투명 색 규칙을 지키도록 검은색을 배경색에 미리 합성한 네 겹의 색 띠와 SVG 직사각형으로 구성했다. 블러나 반투명 오버레이 없이 모서리를 단계적으로 잘라 둥근 인상을 준다.
검증 및 남은 상태
  • TypeScript type-check, 변경 파일 ESLint, 관련 Jest 23개 통과. i18n 5개 언어 키 검사와 런타임 require cycle 0건 확인.
  • localhost 375px 브라우저에서 상단 버튼, 핸드폰 알림 목록·상세, 앱 탭의 AI 뮤지엄 이동을 확인했다. 알림 상세 클릭 후 콘솔 오류 0건.
  • 전체 npm run verify는 완료하지 않았다. check:pixel-rules가 작업 범위 밖 화면의 위반 4건 증가(146→150)를 보고해 실패한다. 이 보고서는 그 게이트를 통과했다고 주장하지 않는다.
  • 네이티브 Android/iOS 실제 기기에서 제스처·레이아웃은 이번 검증 범위에 포함되지 않았다.
