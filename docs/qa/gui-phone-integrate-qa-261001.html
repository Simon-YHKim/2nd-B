결함별 원인과 수정

1. 사건 상세 본문 0px

스타일 배열 [sheetScroll { flexGrow: 0 }, phoneSheetScroll { flex: 1 }]. Yoga(네이티브)와 react-native-web 모두 명시한 flexGrow가 flex 축약보다 이겨서 grow 0, basis 0이 됐어요. flexGrow: 1, flexShrink: 1, flexBasis: 0, minHeight: 0으로 바꿨어요. 이 결함은 네이티브에서도 같은 해석이라 앱에서도 났을 가능성이 커요(앱으로는 미확인).

2. 타임라인 캔버스 0px

[viewport { flex: 1 }, phoneViewport { flex: 0, height: 400 }]. react-native-web 0.21은 flex: 0을 CSS에 그대로 넘기고, CSS는 그것을 0 1 0%로 읽어요. basis 0%가 height를 덮어써서 0px이 됐어요. Yoga는 flex: 0을 basis auto로 읽으니 네이티브에서는 안 났을 수 있어요(미확인). flexGrow: 0, flexShrink: 0, flexBasis: "auto", height: 400으로 바꿨어요.

3. 뒤로 가기 두 개

핸드폰의 'Back 줄'과 Ops 화면 머리의 화살표가 둘 다 backInside를 불렀어요. contentOwnsBack(뮤지엄 또는 Ops 7개 경로)일 때 핸드폰 줄을 숨겨요. Ops 7개 화면은 모두 최상위에서 OpsFrame을 그리고 그 전에 빠져나가는 return이 없어서, Back 없는 화면이 생기지 않아요. 안드로이드 하드웨어 Back은 그대로 핸드폰 기록을 한 단계씩 돌아가요.
