대시보드 연결 상태 정리

대시보드에서 연결 상태·데이터 출처 표와 관리 버튼, 읽은 시각·갱신 주기 안내를 제거했다. 연결과 갱신 설정은 기존 설정 화면에 남겼다.

화면 정리 완료판단에 필요한 카드·그래프만 표시
저장 자료 자동 읽기대시보드 진입 때 계정 범위의 기존 자료를 읽음
외부 자동 연결 미구현서비스별 로그인·동의 커넥터가 아직 없음
구현 범위

DashboardPhone.tsx에서 연결 상태 표와 관련 상태·스타일을 제거했다. phone-settings-contract.test.ts에 대시보드 비표시와 첫 진입 자동 읽기 계약을 추가했고, src/lib/dashboard/README.md에 현재 연결 범위를 명시했다. 설정의 자료 출처·동의·가져오기·주기 선택 기능은 변경하지 않았다.

검증 및 남은 한계

집중 테스트 9개 통과, 타입 검사 통과, 변경 파일 ESLint 통과. 로컬 425×812 브라우저에서 연결 표·읽은 시각·주기 문구가 사라진 것을 확인했다. 전체 npm run verify는 변경 범위 밖 기존 PIXEL-CLAY 규칙 위반 증가(기준 146→150)에서 중단됐다. 로컬 웹 매니페스트 404와 스타일 경고도 별도 현안이다.

현재 외부 계정 OAuth 자동 연결은 없다. Calendar 등은 사용자가 선택한 파일 가져오기, 건강 자료는 기존 동의·기기 권한 흐름이며 일부 SNS는 직접 커넥터가 없다. 로그인 요청까지 이어지는 자동 구축은 공급자별 인증·권한·철회·동기화 기능을 별도로 구현해야 한다.
