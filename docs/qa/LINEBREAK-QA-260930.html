한국어 줄바꿈을 어절 단위로

작성 2026-09-30 17:48 KST · 발행 Claude Code · 등급 S · PR #1933

웹(localhost)과 폰 앱에 같은 규칙이 들어갔습니다.

무엇을

한국어는 띄어쓰기에서만 줄이 바뀌게 했습니다. 가운뎃점(·)이 줄 맨 앞에 오지 않게도 했습니다.

왜

로그인 화면의 "환불 및 청약철회 정 / 책". 재 보니 약관·처리방침·가입 화면에서만 285곳이 이렇게 끊겼습니다.

지금 어디까지

PR #1933 머지(17:02). 폰 QA APK qa-260930-4ee03669를 올렸고, localhost 8081도 같은 빌드로 다시 띄웠습니다(같음 확인). 폰 앱도 에뮬레이터로 확인했습니다.

남긴 것 하나. 뮤지엄 카드에서 영어 단어 "Backpropagation"이 카드보다 길어서 "Backpropagati / on"으로 쪼개집니다. 하이픈을 넣는 기능은 웹과 Android에만 있고 iOS에는 없어서, 넣으면 앱과 localhost가 달라집니다. 한 곳뿐이라 그대로 두기를 권합니다.

어떻게 쟀나

헤드리스 크롬을 폭 393px로 열고, 화면에 그려진 글자마다 위치를 재서 줄이 바뀐 자리를 찾았습니다. 바뀐 자리 양쪽이 모두 한글이면(띄어쓰기 없이) "단어 중간 끊김"으로, 다음 줄 첫 글자가 가운뎃점이면 "줄머리"로 셉니다.

  • 수정 전: 8081. 폰 QA APK qa-260930-f17ce1b3와 같은 빌드입니다.
  • 수정 후: 8082. 이 브랜치를 같은 설정으로 띄운 세션 확인용 서버입니다(앱이 아님).
  • 범위: 로그아웃 화면 9개 × 5개 언어, 로그인 화면 94개 × 한국어·영어. QA 계정으로 로그인했고, AI 호출(/functions/v1)과 분석 스크립트는 막았습니다.

무엇을 바꿨나

  • 웹: +html.tsx에서 <html>에 word-break: keep-all 한 줄을 걸었습니다. 상속되는 속성이라 모든 글자·입력칸에 닿습니다. 라틴 문자에는 영향이 없고, 칸보다 긴 단어는 여전히 다음 줄로 넘어갑니다.
  • 폰 앱: React Native에는 같은 스타일이 없습니다. 그래서 새 컴포넌트 PlainText가 한글 단어의 음절 사이에 보이지 않는 연결 문자(U+2060)를 넣습니다. 이미 11곳에서 손으로 쓰던 방식이고, 폰에서 검증된 방식입니다.
  • 범위: 공용 <Text>와, React Native의 Text를 직접 쓰던 64개 파일이 모두 PlainText를 거치게 했습니다. 파일마다 import 한 줄만 바뀌었습니다.
  • 사용자 글 보호: 복사할 수 있는 글(selectable)은 건드리지 않습니다. 이모지 조합(가족 이모지, ❤️, 피부색, 국기, 키캡)은 쪼개지 않습니다. 화면 읽기 프로그램에는 원문이 전달됩니다.
  • 재발 방지: plain-text-guard.test.ts가 있어서, React Native의 Text를 직접 가져오는 파일이 다시 생기면 빌드가 실패합니다.

남긴 것

  • "Backpropagati / on"(뮤지엄, 영어): 하이픈 자동 넣기는 웹(hyphens)과 Android만 되고 iOS는 수단이 없습니다. 넣으면 모든 긴 영어 단어의 줄끝 모양이 바뀝니다. 한 곳뿐이라 그대로 두기를 권합니다.
