# Codex → Claude 인수인계

사용자 요청: Codex 사용량이 얼마 남지 않아 Claude에게 이어서 맡긴다.
이 인수인계는 기존 문구·다국어·스토어·세션 설정 작업을 잇기 위한 것이다.
새 기능 개발이나 프로젝트 전체 재설계를 시작하지 않는다.

## 바로 시작할 곳

붙여넣을 지시는 [PROMPT.md](PROMPT.md), 확인 당시 상태는 [snapshot.json](snapshot.json)이다.
현재 제품 지침은 작업할 체크아웃의 `CLAUDE.md`, 공통 진행 규칙은
[세션 시작 안내](../README.md)다. 원래 요청과 현재 코드를 먼저 읽는다.

| 구분 | 위치·상태 |
|---|---|
| 앱 변경 원본 | `E:\2ndB\.worktrees\2ndB\TTL-Work`, `claude/pixelclay-auth-mascot-font-260905` |
| 앱 HEAD | `bcd051ae14c037d876a5e9695b9cf7357dd21aae` — 그 뒤 앱 변경은 미커밋 |
| 공통 인수 자료 | `E:\2ndB\.worktrees\session-start-260906`, `docs/session-start-260906` |
| 공통 읽기 경로 | `refs/heads/docs/session-start-260906`를 SHA로 고정한 뒤 `git show` |
| 공용 정본 | `E:\2ndB`의 main. 직접 편집하지 않는다. |
| 공유 문서 확인 지점 | `681aae2b` — 이 인수 파일을 추가하기 전 확인한 커밋. 최신 ref를 다시 읽는다. |

앱 원본에는 수백 개의 다른 세션 변경이 섞여 있다. `snapshot.json`의 dirty 개수는
촬영 시점의 수치일 뿐이다. 전체 파일·전체 diff를 이 Codex 세션 소유라고 판단하지 않는다.
TTL-Work를 정리하거나 삭제하지 않는다. 공유 문서 브랜치도 앱 통합 브랜치로 쓰지 않는다.

## 완료한 범위와 근거

1. 첫 문구 개선: 5개 언어의 140개 문구와 프롬프트를 다듬었다. 금지어 검사에서 기술 설명·
   일상 질문을 잘못 막던 부분, 부정문 한 구절이 문장 전체를 면제하던 부분을 고쳤다.
   Android 암호화 저장소의 Base64 문자열·바이트 배열 전달 오류도 이 차수에 있다.
   [앞선 인수 기록](../copy-handoff.md), [58개 파일의 당시 목록](phase1-manifest.json)을 읽는다.
   당시 원본·보고·스냅샷은 TTL-Work의 `Output/plain-language-260906/`에 있다.
2. ES/PT/ID 후속: 로케일 117개, 소스 안 ID 문구 4개를 다듬었다. 세컨비의 소개·선택 버튼이
   UI 언어를 읽도록 고쳤고 애착·독점·속마음 단정의 대표 패턴과 회귀 테스트를 추가했다.
   [변경 전후·패치·문맥](../multilingual-copy-260906/README.md)을 읽는다.
   첫 차수와 같은 키를 다시 고친 경우가 있으므로 140과 121을 고유 문구 수로 합산하지 않는다.
3. 실제 잘림 수정: 세컨비 소개의 한 줄 제한 제거, `lineHeight: 18` 적용.
   [text-clipping.patch](../multilingual-copy-260906/text-clipping.patch)는
   [app-copy.patch](../multilingual-copy-260906/app-copy.patch) 다음 수정이다.
   앞선 미커밋 코드가 전제이므로 main에 바로 적용된다고 가정하지 않는다.
4. 스토어: [초안 정본](../../store-copy/drafts.json), [미리보기](../../store-copy/review.html),
   [등록 전 확인 사항](../../store-copy/README.md). KO/EN/ES/PT/ID 5개 언어,
   메타데이터 35개·촬영용 캡션 30개. ES는 중남미, PT는 브라질 표현이다.
5. Codex·Claude 공통 시작 경로를 이 PC에 설치하고 공유 ref로 연결했다.
   로컬 문서 커밋은 보존돼 있다. 이 세션에서 push·병합·운영 배포는 하지 않았다.

최신 실제 앱 검증은 **2026-09-06 22:37:57 KST**, `npm run verify` 전체 통과,
**707개 묶음·8,641개 테스트 통과**다. [최신 결과](../multilingual-copy-260906/text-clipping-checks.json)를
읽는다. 앞선 `checks.json`의 픽셀 기준선 차이와 연구자료 테스트 실패는 당시 결과다.
다른 작업에서 정리된 뒤 재검증해 통과했다. 실패를 다시 만들거나 옛 기준선으로 되돌리지 않는다.
인수 문서를 쓰면서 앱 테스트를 다시 실행한 것은 아니므로 현재 상태와 구분한다.

잘림 검사는 KO/EN/ES/PT/ID × 320/390/1440px × 기본/160% 소개 글자 크기의 30개 조합이다.
잘림 16 → 0. 웹의 기본 세컨비·빈 대화 배치 검사이며 네이티브 OS 글자 확대 검증은 아니다.
스토어 미리보기는 20개 조합·정확한 복사 140회, 생성기 4개 테스트를 확인했다.

## Claude가 이어서 할 일

먼저 [작업 목록](../tasks.json)과 Git 공통 디렉터리의 `2ndb-session-state/*.json`을 읽는다.
`MULTILINGUAL-COPY-260906`와 `TEXT-CLIPPING-260906`의 `done`은 해당 로컬 수정 완료다.
**main 통합 완료를 뜻하지 않는다.** 다른 소유자의 active 기록이 있으면 그 범위를 가져오지 않는다.

### 1. COPY-INTEGRATE-260906

- 현재 main과 위 원본·키별 diff·패치를 대조해 이미 들어간 것과 미반영 변경을 구분한다.
- 공유 main을 편집하지 말고 `E:\2ndB\.worktrees/<이름>`에 자신의 통합 워크트리를 둔다.
  이 프롬프트가 TTL-Work의 다른 세션 변경까지 편집할 권한을 주는 것은 아니다.
- 첫 차수의 전체 파일 목록은 탐색 출발점이다. 일부 파일은 당시 스냅샷이 없어 목록에
  `snapshotAvailable: false`로 표시돼 있다. 이 파일은 현재 코드·관련 테스트와 대조한다.
- 문구·문맥 검사·회귀 테스트·필요 문서를 함께 옮긴다. 기존 코드를 덮어쓰는 대신 필요한
  diff만 정리하고, 관련 검사와 `npm run verify`를 실행한다.
- 파일별 반영 여부와 남은 항목을 기록한다. 앞선 통과 기록을 이번 검증 결과로 쓰지 않는다.

### 2. STORE-REVIEW-260906 / PUBLIC-COPY-260906

- 제출할 앱 버전·식별자·언어와 초안을 대조하고, 공개 대상 소개·공유·지원 페이지를 확인한다.
- 출시 Android/iOS 빌드, 원어민 감수, 실제 콘솔 문구 대조와 새 플랫폼 스크린샷은 아직이다.
  캡션 작성이나 Android debug 확인을 출시 이미지·iOS 검증 완료로 보고하지 않는다.
- 콘솔 저장·심사 제출·공개·배포·push·병합은 기존에 위임됐는지 확인한다. 이번 인수 요청이
  그 권한을 새로 주지는 않는다. 승인 전에도 가능한 로컬 준비와 검토는 끝까지 수행한다.

## 유지할 기준

- AI스러운 칭찬·홍보·번역투를 쓰지 않는다. [STYLE.md](../../../STYLE.md)의 문맥 기준을 따른다.
  단어만 보고 금지하지 않고 기능·저장 상태·출처·동의 의미를 보존한다.
- 실제 기록 없이 사용자의 성격·감정·속마음을 단정하지 않는다. 친근한 인사·일반 안내·
  경험 질문과 AI의 애착·독점 주장을 구분한다.
- `SystemLocale`은 EN/KO다. ES/PT/ID 안전·동의 안내는 승인된 기존 영어 사본이다.
  beta 표시·정형 설문·동의 체크문을 문체 통일만을 이유로 바꾸지 않는다.
- 실제 AI 검증이 필요하면 현재 한도와 비용부터 확인한다. 이전 QA는 일일 한도에 도달했다.
  자격증명은 프로젝트 지침의 로컬 위치에서만 읽고 프롬프트·보고에 넣지 않는다.
- 완료한 문구를 처음부터 다시 쓰지 않는다. 이미 받은 정보를 재질문하거나 계획만 내놓고
  끝내지 말고, 현재 요청 범위에서 수정·검증·인수 기록까지 진행한다.

## 이번 인수의 종료 상태

Codex는 앱 수정과 위 로컬 검증을 마치고 이 인수 자료를 남겼다. 이 세션이 시작한
웹 검증용 서버는 종료했다. Claude가 실행되지 않은 상태에서 전달·착수했다고 보고하지 않는다.
문서 경로·공통 ref·현재 snapshot을 확인한 뒤 진행 상황을 한 줄 알리고 시작하면 된다.
