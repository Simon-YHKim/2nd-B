설정한 내용
  • Codex의 기존 전역 지침 끝에 2ndB 전용 연결을 추가했다. 기존 바이트는 보존했다.
  • Claude는 별도 개인 규칙 파일을 추가했다. 생성물인 전역 CLAUDE.md는 바꾸지 않았다.
  • 현재 요청 우선, 현황만 묻는 경우 읽기만 수행, 작업 선점과 완료 기록, 다음 세션 인수 절차를 남겼다.
  • 문서용 CLAUDE.md의 낡은 경로와 고정 파일 수·계획 승인·강제 세션 종료 규칙을 정정했다.
  • 스토어 KO/EN 초안과 원본 비교 자료를 로컬 Git 브랜치에도 보존했다.
검증 근거

두 도구의 새 CLI 세션이 공유 문서를 읽고 첫 작업 COPY-INTEGRATE-260906, 초안 docs/store-copy/drafts.json을 찾았다. 구체적인 요청 우선과 현황 질문 시 수정하지 않는 기준도 확인했다.

적용 범위와 남은 일

동일 Windows 계정과 E:\2ndB의 Git 저장소·워크트리에 적용된다. 이미 열린 세션 대신 새 세션에서 시작한다. 웹 채팅, 다른 PC와 별도 clone에는 이 로컬 연결이 자동 전달되지 않는다.

이번 확인은 지침 발견·문서 읽기·작업 식별까지다. 실제 후속 작업 집행과 다른 소유자의 작업 재개, 운영 콘솔은 시험하지 않았다. 앱 코드 수정이 없어 전체 앱 검증은 다시 실행하지 않았다.

자료는 docs/session-start-260906에 로컬 커밋했다. main 체크아웃은 직접 수정하지 않았고 push·병합·배포·스토어 반영은 하지 않았다.
