## "Gemini로 안 감" 근거 -- 측정값이 LLM에 안 들어감 (CONFIRMED)

1. 읽기 경로: "No network, no LLM, $0" -- src/lib/health/sources/health-connect.ts:10-11.
2. ingest: 결정론적, no LLM -- src/lib/health/ingest.ts:11 (자동완료도 규칙표 기반, no LLM).
3. health_samples 소비자는 셋, 전부 no LLM / no network:
   - src/lib/persona/load-domain-levels.ts:116-121 -- select("source").limit(1) 만. 건강 도메인 레벨에 "기기 소스 존재" 1비트로만 기여(값 미열람).

   - src/components/deep-space/DomainStarLens.tsx (HealthLens) -- 최근 값을 화면에 표시(온디바이스 UI, 심박 포함). 외부 전송 없음.
4. health_samples 는 wiki 스냅샷(daily-brief/chat 의 LLM 컨텍스트)에 포함되지 않음 (grep 확인).

결론: 걸음·운동·수면·심박수 측정값은 어떤 LLM 프롬프트에도 들어가지 않는다(표시는 전부 온디바이스). 파생 '레벨' 숫자가 persona/gap LLM 콜에 들어가는지는 S2 배선 영역이나, 건강 기여분은 존재 1비트뿐이라 측정값 노출은 0. 선언 문구는 "측정값 미전송"으로 안전.
