## 부수 발견 — BOOTSTRAP에 흡수할 후보 2건

**(1) 마운트된 리눅스 셸에서 git status를 믿으면 안 된다.**
Cowork의 리눅스 VM은 `C:\2ndB` 를 마운트해 보여주는데, 거기서 git을 돌리면 CRLF 때문에
추적 파일 전부가 ` M` 으로 보인다. `core.filemode=false`인데도 그렇다.

```
(리눅스 마운트) git status --porcelain -> 수백 건 M
(Windows PS)    git status --porcelain -> 6건, 전부 ?? untracked asset
(리눅스 마운트) git diff README.md     -> 125 insertions(+), 125 deletions(-) 전량 CRLF
```

여기서 `git add` 를 했으면 리포 전체를 줄바꿈만 바꿔 다시 커밋할 뻔했다.
BOOTSTRAP §4의 `git add -A` 금지와 같은 계열의 함정이다.

**(2) `C:\2ndB` 의 node_modules 가 불완전하다.**

```
node node_modules/expo/bin/cli config --json
  PluginError: Failed to resolve plugin for module "@react-native-firebase/app"
```

이 때문에 `eas` CLI 전 명령이 실패한다(`build:list`, `build:view`, `update:list`).
우회는 EAS GraphQL API 직접 호출(`https://api.expo.dev/graphql`, `~/.expo/state.json`의 세션으로 인증).
**재설치는 하지 않았다** — `npm ci` 는 node_modules를 먼저 지우는데 S1~S6이 같은 트리에 붙어 있어
파괴적 게이트다. 재설치 여부는 함대 합의가 필요하다.
