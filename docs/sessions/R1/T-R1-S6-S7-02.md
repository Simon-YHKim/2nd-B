## 실행 순서

1. `git fetch origin main` 후 `gh pr checks 1149`를 실행한다.
2. `#1149`가 green·mergeable이면 먼저 머지한다. 자동 머지는 사용하지 않는다.
3. `#1156`을 최신 main으로 갱신하고 checks green을 다시 확인한 뒤 머지한다.
4. `#1154`도 같은 방식으로 갱신·재검증한 뒤 머지한다.
5. 마지막으로 `git fetch origin main` 후 아래 정본 파일이 실제 main에 있는지 확인한다.

```powershell
git show origin/main:docs/sessions/BOOTSTRAP.md
git show origin/main:docs/sessions/R1/BOARD.md
git show origin/main:docs/sessions/R1/T-R1-S6-S7-01.md
git show origin/main:docs/sessions/R1/T-R1-S6-S7-01-reply.md
git show origin/main:docs/sessions/R1/T-R1-S7-S6-08-reply.md
git show origin/main:src/lib/persona/north-star.ts
```

각 PR의 merge commit이 확인되면 다음도 실행한다.

```powershell
git merge-base --is-ancestor <merge_sha> origin/main
```

exit code 0일 때만 main 실반영을 `CONFIRMED`로 기록한다. PR의 Merged 배지만으로 완료 처리하지 않는다.
