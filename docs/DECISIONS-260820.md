## P1 — 픽셀 격자 `--u` = **2px**

번들의 `--u` 는 뷰포트로 갈린다(`<640px` 2px · `640-1279px` 3px · `≥1280px` 4px).
390px 폰은 **2px** 구간이므로, 이 선택은 **CSS 가 실제 폰에서 만들어내는 값**이다.

RN 에는 뷰포트 미디어 쿼리가 없으므로 `--u` 는 **상수 2** 로 고정한다. 간격 스케일은
전부 그 배수다: `s1=2 · s2=4 · s3=6 · s4=8 · s5=10 · s6=12 · s8=16 · s10=20 · s12=24 ·
s16=32 · s20=40 · s24=48 · s32=64 · s48=96 · s64=128`.

> ⚠ **인수 스크린샷 12장은 `--u:4px` 에서 찍혔다.** 데스크톱 창에서 촬영됐기 때문이다.
> 그래서 2px 로 만든 화면은 **그 스크린샷보다 촘촘하고 작게** 보인다 — 시안과 다른 것이
> 아니라 **시안이 실제 폰보다 두 배로 찍혀 있었던 것**이다.
>
> 되돌리려면 상수 하나(`u`)만 4 로 바꾸면 된다. 그게 P5(토큰 층부터)를 고른 이유이기도 하다.

## P3 — Galmuri 3종 추가

저장소에 `Galmuri11` 은 **이미 있다**(`assets/fonts/Galmuri11-subset.{ttf,woff2}` +
`typography.ts:48-51` + `docs/ASSETS.md` SIL OFL 고지). 앱 기본 본문 서체도 이미 픽셀이다.

추가할 것은 **Galmuri14(디스플레이) · Galmuri9(10px 마이크로) · GalmuriMono11(숫자·라벨)**.
원본은 이미 쓰고 있는 `galmuri` npm 패키지. 라이선스 고지는 `docs/ASSETS.md` 한 줄 확장.

> ⚠ `.ttf` 가 2.5MB 다. **3종을 더하기 전에 서브셋 범위와 번들 크기를 먼저 잰다.**

## P4 — 디더 = 작은 타일 이미지 반복

타일 PNG 를 `resizeMode="repeat"` 로 깔면 픽셀이 정확히 떨어지고 가장 빠르다.

## B4 — 코드에 박힌 한국어를 i18n 으로 걷어낸다

⚠ **먼저: `locales/` 안의 EN 은 이미 진짜 영어다.** 3,532키 완전 패리티, 한글 포함 값 9개는

**대상은 그 밖이다:**

| | |
|---|---|
| `src` **코드**의 한글 줄 | **2,553줄 / 173파일** |
| 그중 EN 경로가 아예 없는 파일 | **425줄 / 36파일** |
| 캐논 JSON 문자열 중 한글 | **1,926 / 3,840** |

성격상 한국어가 맞는 것은 제외한다 — **법률 문서**(한국 관할, `legal-documents.ts` 138줄) ·
**개발 전용 화면**(`screen-index.ts` · `dev-screens.tsx` · `DeepSpaceHubDockScreen.tsx`).

나머지 대부분은 **i18n 을 우회하는 인라인 로케일 표**다(`PERSONA_COPY` ·
`AXIS_RESULT_COPY` 같은 `Record<AvailableUiLocale, …>`). 번역이 없는 게 아니라
**번역이 i18n 밖에 있는** 것이므로, 옮기는 작업이지 번역 작업이 아니다.

⚠ **`check:constraints` 가 소스의 리터럴 `t("키")` 를 grep 한다.** 키를 변수로 빼면 깨진다.

### ⚠ 2026-08-20 실행 결과 — 위 숫자가 틀렸다

"코드에 박힌 한국어 2,553줄" 은 **두 가지를 잘못 센 숫자**다:

1. `case "home": // 별자리` 같은 **꼬리 주석**을 코드로 셌다
2. **매칭 규칙**과 UI 카피를 구분하지 않았다

주석을 빼고 **문자열 리터럴만** 다시 세면 — 법률·개발 화면 제외 후 —
**EN 경로가 없는 파일은 29개**다. 그리고 그 대부분은 번역하면 **앱이 고장 난다**:

| 파일 | 한국어가 맞는 이유 |
|---|---|
| `detect-domain.ts` (86) | 도메인 분류 키워드 → 번역하면 분류가 죽는다 |
| `lexicon.ts` (62) | 금지어 패턴 → 번역하면 안전 검사가 죽는다 |
| `finance-csv.ts` (47) | 한국 은행 CSV 컬럼명 → 번역하면 가져오기가 죽는다 |
| `crisis-eval-corpus.ts` (34) | 위기 평가 픽스처 → 번역하면 평가가 무의미 |
| `recommend.ts` · `daily-brief.ts` | LLM 시스템 프롬프트 (UI 아님) |
| `records-timeline.ts` 등 | 한국어 **폴백** — 화면은 이미 `t()` 를 넘긴다 |

**실제로 사용자에게 보이는 하드코딩은 하나였다** — `InlineLoader` 의 접근성 라벨
("불러오는 중"). 로딩마다 뜨고 15개 파일이 쓴다. i18n 키가 이미 5로케일에 있었고
쓰지 않고 있었을 뿐이라, 배선만 고쳤다.

**남은 것은 "번역"이 아니라 "분류"다.** 그래서 옮기는 대신 **가드**를 세웠다 —
`src/lib/i18n/__tests__/korean-in-code.test.ts` 가 EN 경로 없이 한국어 문자열을 들이는
새 파일을 막고, 면제하려면 **이유를 적게** 한다. 이유를 못 대면 그건 i18n 으로 뺄 카피다.
